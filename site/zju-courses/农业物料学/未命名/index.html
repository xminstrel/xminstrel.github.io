    农业物料学 2026-05-06 第 3-4 节

    约 2,535 字 约 7 分钟

    1. 课堂一句话概览

    本节课围绕农业物料的力学与流变学评价展开，主要讲解了两大块内容：一是通过动态力学试验及模拟破坏性试验（如 TPA）来评价固体与半固体物料的质地；二是系统介绍液体农业物料的流动特性，包括牛顿与非牛顿流体的分类、流动曲线意义及黏度影响因素，并初步探讨了压力差法测定流变参数的原理。

    2. 课程主线

    课程推进逻辑清晰，按以下顺序展开： 1. 动态力学试验原理：从物料分类入手，引入施加小幅振荡的动态试验，讲解理想弹性体、粘性体与粘弹体在正弦波作用下的应力-应变相位差，引出复数模量（储能模量 G‘与损耗模量 G“）的核心概念。 2. 动态试验方法与装置：介绍了纵向振动法（用于固体）与剪切振动法（用于半固体/液体），并说明了频率对模量的影响。 3. 模拟破坏性试验：过渡到通过模拟人咀嚼、切割等动作来评价农产品口感的测试方法，重点讲解了 TPA（质构剖面分析）的原理、参数定义，并列举了剪切、穿刺、挤出、拉伸等多种测试类型及其应用。 4. 液体物料流变学基础：转向液体物料，强调流动曲线的重要性，系统划分了非牛顿流体的类型（假塑性、胀流性、塑性、触变性、震凝性），同时指出温度、浓度、压力是影响黏度的关键因素。 5. 流变参数测量方法（压力差法）：讲解基于层流假设的毛细管法原理，推导利用压差与流量推算剪切应力与剪切速率关系的基本思路，并对比指出该方法对非牛顿流体操作繁琐。 6. 课程要求：老师明确本章为考察重点，需掌握前 5 节内容，并完成配套测试题与两次作业。

    3. 核心知识点

    • 动态试验的基本概念
    • 施加小幅正弦波应变，物料不破坏。
    • 理想弹性体：应力与应变同相位（相位差 0）。
    • 理想粘性体：应力与应变相位差90°(π/2)。
    • 粘弹体：相位差介于0~π/2之间。
    • 复数模量：
      • 储能模量 G‘：与应变形变同相位的弹性部分，反映能量储存。
      • 损耗模量 G“：与应变速率相关的粘性部分，反映能量耗散。
    • 农产品质地的模拟力学试验
    • 通过破坏性试验评价口感，如嫩度、硬度等。
    • TPA（质构剖面分析）：模拟牙齿两次压缩过程。
      • 从力-时间曲线中定义：
      • 硬度：第一次压缩的峰值力。
      • 凝聚性：两次压缩峰面积比。
      • 弹性、咀嚼性、粘着性等。
    • 其它试验：剪切（奶酪、肉）、穿刺（水果硬度）、挤出（面包）、拉伸（口香糖）。
    • 液体物料的流动曲线与分类
    • 流动曲线：描述剪切应力(τ)与剪切速率(γ̇)的关系。
    • 牛顿流体：τ与γ̇成正比，黏度(μ)为常数。例如：硅油、特定温度下的蜂蜜。
    • 非牛顿流体（与时间无关）：
      • 假塑性：n<1，表观黏度随γ̇增大而减小。如：蛋黄酱、番茄酱。
      • 胀流性：n>1，表观黏度随γ̇增大而增大。如：某些浓淀粉糊。
      • 塑性(Bingham)：存在屈服应力(τ₀)，需克服后才能流动。如：鲜奶油、牙膏。
    • 非牛顿流体（与时间有关）：
      • 触变性：受搅动变稀，静止变稠。
      • 震凝性：受搅动变稠，静止变稀。
    • 表观黏度(η_app)：非牛顿流体在某剪切速率下的τ/γ̇比值，不是定值。
    • 影响黏度的因素
    • 温度：影响显著（指数级），温度升高，黏度急剧下降。
    • 浓度：浓度增大，黏度增大。
    • 压力：压力升高，黏度一般升高。
    • 重要原则：给出黏度数据时必须注明温度和浓度。
    • 流变参数测量法（毛细管法/压力差法）
    • 原理：假设为层流，利用压差ΔP、管半径 R、管长 L 求得管壁处的剪切应力τ_w = ΔP·R / 2 L。
    • 过程：测量压差和流量，通过积分反推剪切速率，绘制流动曲线。
    • 局限：仅适用流动性好的流体；对非牛顿流体需进行多组不同压差的测量，操作繁琐。

    4. 重点与难点

    重点

    1. 粘弹性概念：深刻理解储能模量(G‘)与损耗模量(G“)及其与相位差的关系。
    2. 非牛顿流体的识别：能根据流动曲线形状和时间依赖行为，准确区分假塑性、塑性、触变性等流体，并背诵典型例子（如蛋黄酱、番茄酱）。
    3. TPA 原理与参数：掌握 TPA 测试如何模拟咀嚼过程，以及硬度、凝聚性等参数在曲线上的定义。
    4. 影响黏度的核心因素：牢记温度和浓度是影响黏度的最主要因素，给出黏度值必须附带条件。

    难点与易错点

    1. 粘弹体应力分解：容易混淆弹性部分是跟应变同相位还是跟速率同相位。提示：弹性部分(G‘)与应变成正比（同相位），粘性部分(G“)与应变速率成正比（领先 90°）。
    2. 非牛顿流体分类混淆：
      • 假塑性是“剪切变稀”，胀流性是“剪切变稠”，两者性质相反。
      • 触变性和震凝性(反触变)的区别在于时间依赖性，不要记反。
      • 塑性流体有屈服应力，这是它与假塑性流体的关键区别。
      • 牛顿流体不等于理想流体（理想流体无黏性）。
    3. 表观黏度的理解：非牛顿流体的“黏度”随剪切速率变化，不能用一个单一的数值来描述，必须指出是在哪个剪切速率下的表观黏度。
    4. 压力差法的适用范围：该方法前提是层流，不适用于高黏度或非牛顿流动性复杂的物料。
