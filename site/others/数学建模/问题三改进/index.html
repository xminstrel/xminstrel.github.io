    下面给你一份问题三改进方案，可以直接作为你论文里“模型改进与最终选址方案”的基础版本。

    你当前结果已经建立了“选 8 个地点、每地承办 2 个小组”的选址—分配模型，并输出了杭州市、宁波市、绍兴市、嵊州市、金华市、台州市、衢州市、丽水市这 8 个地点；当前结果覆盖 6 个区域、县级承办点数量为 1、平均到赛地距离为 131.03 km、最远距离为 260.75 km、主场关联惩罚为 1.50。
    这个结果偏向公平优先、中立场优先，但对“扩大赛事影响和普及面”体现还可以加强。

    一、改进方向总览

    约 3,617 字 约 10 分钟

    当前模型最大的问题不是“错”，而是价值取向偏单一：

    它较强地压低了主场关联，使市级队基本不能在本市或相关区域比赛。
    这有利于公平，但可能削弱城市联赛的本地观众参与和传播热度。

    因此建议把问题三从：

    公平优先型中立场模型

    改为：

    公平—影响力折中型选址模型

    核心改动有 4 个：

    改进点 原模型问题 改进方式
    主场机制 只惩罚主场优势 同时考虑主场带来的传播收益
    区域均衡 只看覆盖区域数 加入区域承办点数量均衡
    县域普及 县级承办点只有 1 个 设置 2—3 个县级承办点
    选址解释 结果偏中立 给出公平优先、影响力增强、折中三类方案

    二、改进后的模型思路

    1. 继续保留原有基本约束

    原有约束是正确的，不需要推翻。

    选择 8 个比赛地点：

    [
    \sum_{v\in V}y_v=8
    ]

    每个小组分配到一个地点：

    [
    \sum_{v\in V}z_{gv}=1,\quad \forall g\in G
    ]

    每个地点承办两个小组：

    [
    \sum_{g\in G}z_{gv}=2 y_v,\quad \forall v\in V
    ]

    小组只能分配给被选地点：

    [
    z_{gv}\leq y_v,\quad \forall g,v
    ]

    这些约束继续保留。

    三、改进一：主场优势不要一味压到最低

    1. 原来的问题

    你当前模型里主场优势惩罚为：

    [
    H=\sum_{g\in G}\sum_{v\in V}z_{gv}h_{gv}
    ]

    并且在目标函数中最小化它。

    这样会导致模型倾向于：

    尽量让队伍避开自己的所在地或所属市域。

    这解释了为什么市级队基本无法回到自己的主场比赛。

    2. 改进后的主场机制

    建议把主场关联拆成两部分：

    指标 含义 方向
    (H_{\text{adv}}) 主场优势惩罚 越小越好
    (H_{\text{att}}) 主场观众与传播收益 越大越好

    主场优势惩罚：

    [
    H_{\text{adv}}=\sum_{g\in G}\sum_{v\in V}z_{gv}h_{gv}
    ]

    主场传播收益：

    [
    H_{\text{att}}=\sum_{g\in G}\sum_{v\in V}z_{gv}\sum_{t\in T_g}a_{tv}A_t
    ]

    其中：

    [
    a_{tv}=
    \begin{cases}
    1, & \text{队伍 }t\text{ 所在地与比赛地点 }v\text{ 相同}\
    0.5, & \text{队伍 }t\text{ 与比赛地点 }v\text{ 同属一个市域}\
    0, & \text{否则}
    \end{cases}
    ]

    (A_t) 表示队伍关注度，可以由人口、经济、文旅或综合影响力构造。

    这样模型就变成：

    主场不是绝对坏事，而是既有公平损失，也有传播收益。

    四、改进二：设置“适度主场”区间

    为了避免模型完全回避主场，也避免主场过多，建议设置区间约束。

    定义强主场小组数：

    [
    N_{\text{home}}=\sum_{g,v}z_{gv}s_{gv}
    ]

    其中：

    [
    s_{gv}=
    \begin{cases}
    1, & \text{第 }g\text{ 组中至少有一支队伍所在地等于比赛地点 }v\
    0, & \text{否则}
    \end{cases}
    ]

    建议约束为：

    [
    3\leq N_{\text{home}}\leq 6
    ]

    含义是：

    16 个小组中，允许 3 到 6 个小组存在明确主场关联。

    如果你觉得强主场太多，可以设置为：

    [
    2\leq N_{\text{home}}\leq 4
    ]

    这是更稳妥的版本。

    五、改进三：增加县级承办点数量约束

    当前结果只有 1 个县级承办点嵊州市。
    为了更好体现“普及面”，建议加入：

    [
    2\leq \sum_{v\in V_{\text{county}}}y_v\leq 3
    ]

    含义是：

    8 个承办点中至少 2 个、至多 3 个为县级市或县。

    为什么不建议太多？

    因为每个地点要承办两个小组，即 12 场小组赛，对场馆、住宿、交通和组织能力都有要求。县级承办点过多可能影响办赛质量。

    所以 2—3 个比较合理。

    六、改进四：区域覆盖从“覆盖数”升级为“覆盖均衡”

    当前模型用了区域覆盖数：

    [
    U=\sum_r q_r
    ]

    但它只能说明“覆盖了几个区域”，不能说明各区域承办点是否均衡。

    例如当前 8 个地点中浙东有宁波、绍兴、嵊州 3 个点，浙东偏多。

    建议增加区域均衡惩罚：

    [
    B_{\text{region}}=\operatorname{Var}(N_1,N_2,\dots,N_R)
    ]

    其中：

    [
    N_r=\sum_{v\in V_r}y_v
    ]

    表示第 (r) 个区域的承办点数量。

    方向：越小越好。

    也可以设置简单约束：

    [
    1\leq N_r\leq 2,\quad \forall r
    ]

    如果区域数为 6，选 8 个点，那么比较理想的结构是：

    2 + 2 + 1 + 1 + 1 + 1

    也就是最多两个区域有 2 个承办点，其余区域各 1 个。
    这样比当前“浙东 3 个点”的结构更均衡。

    七、改进后的综合目标函数

    建议将目标函数改为：

    [
    \min Z=
    \alpha \widetilde{D}{\text{avg}}
    +\beta \widetilde{D}    }
    +\gamma \widetilde{D}{\max}
    +\eta \widetilde{H}    }
    +\rho \widetilde{B}{\text{region}}
    -\lambda \widetilde{I}
    -\mu \widetilde{U}
    -\theta \widetilde{H}    }
    ]

    其中所有指标都先标准化到 ([0,1])。

    各项含义：

    指标 含义 方向
    (\widetilde{D}_{\text{avg}}) 平均出行距离 越小越好
    (\widetilde{D}_{\text{fair}}) 出行距离差异 越小越好
    (\widetilde{D}_{\max}) 最远出行距离 越小越好
    (\widetilde{H}_{\text{adv}}) 主场优势惩罚 越小越好
    (\widetilde{B}_{\text{region}}) 区域承办点不均衡 越小越好
    (\widetilde{I}) 赛事影响力 越大越好
    (\widetilde{U}) 区域普及面 越大越好
    (\widetilde{H}_{\text{att}}) 主场传播收益 越大越好

    一组可用初始权重为：

    目标 权重
    平均出行距离 0.25
    出行公平性 0.15
    最远出行距离 0.12
    主场优势惩罚 0.10
    区域均衡惩罚 0.10
    赛事影响力 0.13
    区域普及面 0.08
    主场传播收益 0.07

    这组权重的含义是：

    出行便利和公平性仍然占主导，但不再完全压制主场传播价值。

    十、这版改进方案的特点

    1. 不再过度中立

    当前原结果中市级队基本无法到自己的主场比赛。改进方案允许：

    • 温州市所在 G 03 在温州比赛；

    • 嘉兴市所在 G 04 在嘉兴比赛；

    • 丽水市所在 G 11 在丽水比赛；

    • 一些县级队在同市域承办点比赛。

    这增强了观众参与和城市话题性。

    2. 主场优势仍然可控

    改进方案没有让所有市级队回主场，例如：

    • 杭州市所在 G 01 不在杭州；

    • 宁波市所在 G 02 不在宁波；

    • 衢州市所在 G 08 不在衢州；

    • 金华市所在 G 07 不在金华市本地，而在义乌市。

    所以它不是“主场最大化”，而是：

    少量强主场 + 若干半主场 + 多数中立场。

    这比完全中立更符合城市联赛的传播特征，也比全主场更公平。

    3. 县域普及面更强

    当前结果只有嵊州市一个县级承办点。
    改进方案增加义乌市作为第二个县级承办点：

    [
    \text{县级承办点数量}=2
    ]

    这更符合“扩大赛事影响和普及面”的要求。

    4. 区域分布更均衡

    改进后 8 个地点分布大致为：

    区域 承办点
    浙北 杭州、嘉兴
    浙东 宁波、嵊州
    浙中 义乌
    浙南 温州
    浙西 衢州
    浙西南 丽水

    区域结构为：

    [
    2+2+1+1+1+1
    ]

    比当前浙东 3 个点的结果更均衡。

    注意最后一项：
    由于我这里没有重新跑你的 venue_selector.py，所以不能声称改进方案的平均距离一定优于原方案。你应该在代码里把这套地点作为候选初始解或强制地点，重新计算：

    • 平均距离；

    • 最远距离；

    • 出行公平性；

    • 主场惩罚；

    • 主场传播收益；

    • 区域均衡；

    • 影响力指数。

    十二、建议你代码上怎么改

    你可以在 venue_selector.py 中加入三个改动。

    1. 县级承办点数量约束

    county_count = sum(1 for v in selected_venues if venue_info[v]["level"] != "市级")
if not (2 <= county_count <= 3):
    return infeasible_or_penalty

    2. 区域均衡惩罚

    region_counts = Counter(venue_info[v]["region"] for v in selected_venues)
region_values = list(region_counts.values())
region_balance_penalty = np.var(region_values)

    更严谨一点，要把没有选到的区域也算 0：

    all_regions = ["浙北", "浙东", "浙中", "浙南", "浙西", "浙西南"]
region_values = [region_counts.get(r, 0) for r in all_regions]
region_balance_penalty = np.var(region_values)

    3. 主场传播收益

    home_advantage_penalty = 0
home_attraction_bonus = 0

for group in groups:
    venue = assignment[group]
    for team in group_teams[group]:
        if team.location == venue:
            home_advantage_penalty += 1.0
            home_attraction_bonus += team.attention_score
        elif team.parent_city == venue.parent_city:
            home_advantage_penalty += 0.5
            home_attraction_bonus += 0.5 * team.attention_score

    然后目标函数改成：

    score = (
    + w_dist * norm_avg_distance
    + w_fair * norm_distance_std
    + w_max * norm_max_distance
    + w_home_penalty * norm_home_advantage
    + w_region_balance * norm_region_balance
    - w_influence * norm_influence
    - w_coverage * norm_region_coverage
    - w_home_bonus * norm_home_attraction
)

    十三、最终推荐写法

    你可以这样写进论文：

    原模型将主场关联作为单向惩罚项，因而求解结果倾向于回避市级队主场。该方案具有较强的公平性，但不利于充分发挥城市足球联赛的本地观众参与和传播效应。因此，本文进一步提出公平—影响力折中型选址模型，将主场关联分解为主场优势惩罚和主场传播收益两部分，并设置县级承办点数量与区域均衡约束。改进后模型允许少量主场或半主场安排，在控制主场优势的同时提升赛事影响和普及面。

    十四、最终改进方案结论

    我建议你把问题三最终写成：

    当前模型结果作为公平优先方案；
    改进模型结果作为公平—影响力折中方案；
    最终推荐采用折中方案。

    折中方案的 8 个承办点建议为：

    杭州市、宁波市、温州市、嘉兴市、义乌市、嵊州市、衢州市、丽水市

    对应小组安排建议为：

    比赛地点 承办小组
    杭州市 G 08、G 13
    宁波市 G 09、G 14
    温州市 G 03、G 15
    嘉兴市 G 04、G 12
    义乌市 G 05、G 07
    嵊州市 G 01、G 06
    衢州市 G 02、G 16
    丽水市 G 10、G 11

    这版方案相比原方案的改进重点是：

    1. 增加县级承办点数量；

    2. 改善区域承办点均衡性；

    3. 允许适度主场和半主场；

    4. 增强赛事传播和本地观众参与；

    5. 保留基本公平性，不让所有强队都回主场。
