    “浙超”分组方案数学建模总报告

    约 5,940 字 约 15 分钟

    摘要

    本文研究拟议中的浙江省市县足球联赛“浙超”的分组、抽签、承办地选择与赛制优化问题。参赛单位共 64 个，包括浙江省 11 个市级队和 53 个县级队。比赛第一阶段为 16 个小组，每组 4 队进行单循环比赛，小组前两名进入 32 强淘汰赛。

    本题的核心不是简单随机分组，而是一个带有行政回避约束、公平性要求、地理交通因素和赛事传播目标的组合优化问题。本文将分组问题建模为 0-1 整数规划或 CP-SAT 约束规划问题，以“市级队分散”“市级队不与其代管县级队同组”为硬约束，以“同一市代管县级队尽量不同组”“组间实力与影响力均衡”“地域分散合理”为软目标。随后，本文设计一种“分档随机 + 实时可行性检查 + 蒙特卡洛审计”的抽签机制，使抽签既能公开执行，又能保证结果满足约束。对于承办地选择问题，本文将其建模为带容量约束的设施选址问题，在 8 个承办地点每地承办 2 个小组的条件下，综合考虑旅行成本、空间覆盖、城市影响力、场馆能力与主场优势。

    本文使用题面给出的行政隶属关系作为硬约束依据，使用浙江统计年鉴中的人口、GDP、财政、消费和收入数据作为城市影响力与球队潜在实力的代理指标，使用行政区划代码校验参赛单位名称与层级，使用地理坐标或地图服务估计各队旅行距离，并参考体育赛程优化、世界杯抽签公平性、旅行公平和设施选址相关文献建立评价体系。最终目标是在满足全部硬约束的前提下，给出若干可解释、可复现、可比较的分组方案，并从公平性、观赏性、交通便利性和赛事传播效果等维度进行综合评价。

    关键词：数学建模；组合优化；约束规划；公平抽签；设施选址；体育赛程；多目标优化

    1. 问题重述

    拟议中的浙江省市县足球联赛共有 64 个参赛单位，其中包括浙江省 11 个市级单位和 53 个县级单位。赛事分为两个阶段：

    1. 小组赛阶段：64 支队伍分成 16 个小组，每组 4 队，组内单循环比赛，小组前两名晋级。
    2. 淘汰赛阶段：32 支晋级队伍经过 5 轮淘汰赛决出冠军。

    题目要求解决四个问题：

    1. 给出若干满足要求的分组方案，并从不同维度比较优劣。
    2. 设计一种公平、透明、可执行的抽签方案，使抽签结果满足约束并具有较好性质。
    3. 根据分组结果选择 8 个市或县作为小组赛承办地，每个地点承办 2 个小组。
    4. 基于数学模型和定量分析，对赛制提出合理化建议。

    题面明确要求分组遵循以下原则：

    1. 各市级队应分配在不同小组。
    2. 市级队不与该市代管县级队分配在同一小组。
    3. 同一市代管县的县级队应尽量不分配在同一小组。

    前两条是必须满足的硬约束，第三条是“尽量满足”的软约束。

    2. 使用资料及使用理由

    本文使用的资料分为五类：题面资料、官方统计数据、行政区划资料、地理交通数据、运筹优化与体育赛事文献。

    2.1 题面 PDF

    资料：

    • 2026problem.pdf，浙江大学第二十四届大学生数学建模竞赛试题。

    使用理由：

    题面是本题所有硬约束的唯一依据。参赛单位数量、市级队与县级队划分、各县级单位所属市、分组规模、晋级规则和承办地数量均来自题面。因此，题面信息不作为可调参数，而作为模型必须满足的基本约束。

    具体使用：

    • 将 64 个参赛单位整理为 teams_from_problem.csv。
    • 建立市级队集合、县级队集合和县级队所属市映射。
    • 构造“市级队不同组”和“市级队与代管县级队不同组”的硬约束。

    2.2 浙江统计年鉴

    资料：

    • 浙江省统计局，2024 年浙江统计年鉴。
    • 已使用表：
    • 17-25 各市、县国民经济主要指标（2023年）
    • 17-26 各市、县年末人口数（2023年）

    使用理由：

    题目没有提供各参赛队真实竞技实力、球迷基础、场馆容量和城市影响力数据。为了构造可量化的公平性和影响力评价指标，需要引入公开、权威、可复核的数据。浙江统计年鉴提供县市层面的人口、GDP、财政、消费、居民收入等指标，可以作为以下内容的代理变量：

    • 人口：潜在球迷基础、赛事覆盖人数。
    • GDP：地区经济规模、赛事商业影响力。
    • 社会消费品零售总额：消费活跃度和赛事带动潜力。
    • 财政收入：地区公共服务和承办能力的间接反映。
    • 城乡居民收入：居民消费能力和观赛潜力。

    具体使用：

    • 构造“城市影响力指数”。
    • 构造“潜在球队实力代理指数”。
    • 用于比较不同分组方案在影响力均衡、强弱均衡和赛事传播方面的差异。

    需要说明的是，这些指标不能等同于真实球队实力，只能作为没有真实球队数据时的代理指标。因此，最终论文必须对代理指标做权重敏感性分析。

    2.3 行政区划代码资料

    资料：

    • 国家统计局统计用区划和城乡划分代码。
    • 民政部行政区划代码。

    使用理由：

    题面给出了参赛单位及其隶属关系，但在数据处理和外部统计数据匹配时，需要确认县、市、自治县名称的一致性。例如“景宁畲族自治县”应作为县级参赛单位处理，但行政类型不同于普通县。行政区划代码可用于校验名称、层级和归属关系，避免因简称或旧称造成数据匹配错误。

    具体使用：

    • 校验县市名称。
    • 区分市级队、县级市、县、自治县。
    • 在后续扩展地理坐标和统计数据时作为匹配依据。

    2.4 地理与交通数据

    资料：

    • OpenStreetMap Nominatim 或 GeoNames 地理数据。
    • 若条件允许，可使用高德、百度、腾讯地图开放平台路径规划 API。

    使用理由：

    承办地选择和分组地域分散度需要距离或交通时间数据。理想情况下，应使用真实公路或铁路出行时间；如果受限于 API key 或时间成本，可以先使用县市政府驻地经纬度计算球面距离，再通过敏感性分析说明近似误差。

    具体使用：

    • 构造 64 个参赛单位之间的距离矩阵。
    • 构造各参赛单位到候选承办地的旅行成本矩阵。
    • 评价分组的地域分散度。
    • 评价承办地方案的总旅行距离、最大旅行距离和区域覆盖面。

    2.5 体育场地与承办能力资料

    资料：

    • 国家体育总局体育场地统计调查数据。
    • 浙江省体育局及各市县体育局、体育场馆官网。

    使用理由：

    题目要求选择 8 个市或县作为小组赛比赛地点。承办地选择不能只看距离，还应考虑场馆条件、交通便利性、人口覆盖和赛事传播能力。体育场地资料可以支撑承办能力评价。

    具体使用：

    • 判断候选地点是否具备承办足球比赛的基础设施。
    • 构造场馆能力评分。
    • 与人口、GDP、交通距离共同构成承办地综合评价指标。

    如果短时间内无法获得完整场馆数据，第一版模型可先用“参赛单位所在地”作为候选地点，并将场馆能力作为后续修正项。

    2.6 运筹优化与体育赛事文献

    参考方向：

    • 世界杯抽签公平性研究。
    • 体育赛程优化综述。
    • 循环赛赛程公平研究。
    • 旅行距离公平研究。
    • p-median、p-center 和设施选址理论。

    使用理由：

    本题涉及约束分组、随机抽签、赛程公平和承办地选址，这些问题在运筹学和体育赛程优化中已有成熟研究。引用这些文献不是为了堆砌理论，而是为了说明本文模型选择的合理性：

    • 抽签公平性文献支持“受限随机抽签”和“偏差审计”。
    • 体育赛程优化文献支持用数学规划处理赛事组织问题。
    • 旅行公平文献支持将总旅行距离和最大旅行距离作为承办地评价指标。
    • 设施选址理论支持用 p-median / p-center 模型选择 8 个承办地。

    3. 基本假设

    为使问题可建模，本文作如下假设：

    1. 每个参赛单位对应一支代表队，且每支队伍参赛资格相同。
    2. 题面给出的行政隶属关系准确无误。
    3. 市级队分散、市级队与代管县级队不同组为必须满足的硬约束。
    4. 同一市代管县级队不同组为软约束，若完全避免会显著损害其他目标，可允许少量冲突，但应最小化。
    5. 在缺少真实球队实力数据时，人口、GDP、消费、财政和居民收入等指标可作为潜在实力与影响力的代理变量。
    6. 第一版承办地模型可用县市中心点近似代表队伍所在地；若获得真实场馆或交通时间数据，应替换该近似。
    7. 抽签方案必须能由人工公开执行，不能完全依赖黑箱算法。

    4. 符号定义

    设：

    • T 为全部参赛队集合，|T|=64。
    • C 为市级队集合，|C|=11。
    • K 为县级队集合，|K|=53。
    • G 为小组集合，|G|=16。
    • P(k) 表示县级队 k 所属或被代管的市级单位。
    • V 为候选承办地集合。

    定义决策变量：

    x[t,g] = 1，表示队伍 t 被分到小组 g；
x[t,g] = 0，表示队伍 t 不在小组 g。

    承办地变量：

    z[v] = 1，表示地点 v 被选为承办地；
a[g,v] = 1，表示小组 g 安排在承办地 v。

    5. 分组模型

    5.1 硬约束

    每支队伍恰好进入一个小组：

    sum_g x[t,g] = 1,  对所有 t 属于 T

    每个小组恰好 4 支队伍：

    sum_t x[t,g] = 4,  对所有 g 属于 G

    每个小组最多 1 支市级队：

    sum_{t in C} x[t,g] <= 1,  对所有 g 属于 G

    市级队不与其代管县级队同组：

    x[c,g] + x[k,g] <= 1,
对所有市级队 c、县级队 k，若 P(k)=c，对所有 g 属于 G

    5.2 软约束

    同一市代管县级队应尽量不同组。对任意同属一个市的两个县级队 k1,k2，若它们被分到同一小组，则记一次冲突。

    冲突变量：

    y[k1,k2,g] = 1，表示 k1 与 k2 在小组 g 同组

    模型目标之一是最小化：

    same_parent_conflict = sum y[k1,k2,g]

    5.3 多目标评价

    仅最小化行政冲突会忽略竞技公平和赛事传播，因此本文构造综合目标函数：

    min F =
w1 * 同市县级队冲突数
+ w2 * 组间实力代理指标方差
+ w3 * 组间影响力指标方差
+ w4 * 旅行距离不均衡
- w5 * 地域覆盖和观赏性得分

    其中：

    • w1 权重最大，因为行政回避直接来自题目原则。
    • w2 控制各组强弱均衡。
    • w3 控制各组关注度和传播影响力均衡。
    • w4 控制交通便利性。
    • w5 适度鼓励地域覆盖和观赏性，但不能压过公平性。

    不同权重组合可得到不同类型方案：

    1. 公平优先方案：强调行政回避和实力均衡。
    2. 地理便利方案：强调旅行距离和区域分布。
    3. 影响力传播方案：强调人口、GDP 和消费覆盖。
    4. 综合推荐方案：在上述目标间折中。

    最终推荐方案应来自 Pareto 前沿，即不存在另一个方案在所有指标上都不差且至少一个指标更好。

    6. 解题算法

    本文建议采用“三层算法”：

    1. 精确约束求解，保证硬约束满足。
    2. 多目标搜索，生成若干高质量候选方案。
    3. 敏感性分析和模拟审计，判断方案是否稳定可靠。

    6.1 第一层：CP-SAT 或整数规划生成可行解

    步骤：

    1. 读取 teams_from_problem.csv。
    2. 构造 64 支队伍、16 个小组和行政隶属映射。
    3. 建立 0-1 变量 x[t,g]。
    4. 添加硬约束：
    5. 每队唯一；
    6. 每组 4 队；
    7. 市级队不同组；
    8. 市级队与代管县级队不同组。
    9. 添加软约束目标：
    10. 最小化同市县级队同组冲突。
    11. 调用 OR-Tools CP-SAT 或 PuLP 求解。
    12. 输出第一版可行分组。
    13. 用独立检查器再次验证全部硬约束。

    6.2 第二层：加入代理指标做多目标优化

    利用浙江统计年鉴数据，构造每支队伍的指标：

    population_score = 标准化常住人口
gdp_score = 标准化 GDP
consumption_score = 标准化社会消费品零售总额
fiscal_score = 标准化一般公共预算收入
income_score = 标准化居民收入

    构造潜在实力或影响力指数：

    strength_proxy =
alpha1 * population_score
+ alpha2 * gdp_score
+ alpha3 * consumption_score
+ alpha4 * fiscal_score
+ alpha5 * income_score

    其中 alpha 不固定为唯一值，而应设多组权重进行敏感性分析。例如：

    1. 人口优先型；
    2. GDP 优先型；
    3. 消费优先型；
    4. 均衡权重型。

    每个小组的代理实力为：

    group_strength[g] = sum strength_proxy[t] * x[t,g]

    公平性指标为组间方差：

    variance(group_strength)

    方差越小，说明各组强弱越均衡。

    6.3 第三层：局部搜索与 Pareto 筛选

    在精确求解得到可行解后，可以使用局部搜索进一步改进：

    1. 随机选取两个不同小组中的县级队尝试交换。
    2. 检查交换后是否仍满足硬约束。
    3. 若软目标改善，则接受交换。
    4. 若使用模拟退火，可允许少量劣解以跳出局部最优。
    5. 多个随机种子重复运行。
    6. 保存所有非支配解，形成候选方案集。

    该方法的优点是可解释、可控、容易与整数规划结合。整数规划负责可行性，局部搜索负责在多目标评价下继续改进。

    6.4 最终算法流程

    完整流程如下：

    输入：
  题面队伍表、行政隶属关系、统计年鉴数据、地理距离数据

步骤 1：读取并校验 64 支队伍
步骤 2：建立硬约束分组模型
步骤 3：求解可行分组
步骤 4：计算行政冲突、实力均衡、影响力均衡、地域分散等指标
步骤 5：改变权重，多次求解得到候选方案
步骤 6：对候选方案做 Pareto 筛选
步骤 7：对最终候选方案做多 seed 局部搜索改进
步骤 8：输出若干分组方案及分项评价表
步骤 9：设计抽签机制并用蒙特卡洛模拟审计
步骤 10：基于分组结果求解 8 个承办地选择问题
步骤 11：基于模型结果提出赛制建议

输出：
  多个分组方案、评价指标、抽签流程、承办地方案、赛制建议

    7. 抽签方案设计

    分组方案不能只由程序直接指定。为了体现体育赛事的公平与透明，应设计公开抽签流程。

    本文建议采用“分档随机 + 受限抽签 + 在线可行性检查”的方式。

    7.1 抽签步骤

    第一步：设定 16 个空小组。

    第二步：将 11 个市级队作为第一档，随机抽入 11 个不同小组，剩余 5 个小组为空市级小组。

    第三步：将县级队按所属市、实力代理指标或地理区块分成若干档。分档原则是避免同一市县级队集中在同一抽签阶段造成后续不可行。

    第四步：依次抽取县级队。每抽出一支队伍，只允许放入满足以下条件的小组：

    1. 小组未满 4 队。
    2. 若小组已有市级队，该县级队不能属于该市。
    3. 放入后，剩余未抽队伍仍存在完整可行分组。

    第五步：如果某次抽签导致无可行位置，则不是简单全部重抽，而是回溯到最近一次造成不可行的抽签步骤重新抽取。

    第六步：全部抽签完成后，公布完整分组，并运行约束检查。

    7.2 抽签公平性审计

    为避免“看似随机但实际偏向某些队伍”，应对抽签机制做蒙特卡洛模拟。

    模拟次数建议不少于 10000 次。每次模拟完整抽签流程，记录：

    • 每支队伍进入每个小组的概率；
    • 任意两队同组概率；
    • 各队所在小组的平均实力；
    • 抽签失败或回溯次数；
    • 各约束的满足情况。

    评价指标：

    draw_entropy：落组分布熵，越高说明随机性越充分；
pair_bias：两队同组概率相对理想随机值的偏差；
max_group_strength_bias：不同队伍被分到强组的概率差异；
retry_rate：抽签过程回溯或重抽比例。

    如果某些队伍显著更容易进入强组或弱组，需要调整分档方式或抽签顺序。

    8. 承办地选择模型

    题目要求选择 8 个市或县作为小组赛比赛地点，每个地点承办 2 个小组。该问题本质上是带容量约束的设施选址问题。

    8.1 决策变量

    z[v] = 1，表示地点 v 被选为承办地；
a[g,v] = 1，表示小组 g 安排到承办地 v。

    8.2 约束

    选出 8 个承办地：

    sum_v z[v] = 8

    每个承办地承办 2 个小组：

    sum_g a[g,v] = 2 z[v]

    每个小组恰好安排到 1 个承办地：

    sum_v a[g,v] = 1

    8.3 目标函数

    承办地选择应兼顾公平性、便利性和影响力。目标函数可设为：

    min H =
beta1 * 总旅行距离
+ beta2 * 最大单队旅行距离
+ beta3 * 旅行距离方差
- beta4 * 承办地影响力得分
- beta5 * 空间覆盖得分
+ beta6 * 主场优势惩罚

    其中：

    • 总旅行距离反映整体交通成本。
    • 最大单队旅行距离避免个别队伍负担过重。
    • 旅行距离方差反映旅行公平性。
    • 承办地影响力得分由人口、GDP、消费能力和场馆能力构成。
    • 空间覆盖得分鼓励赛事覆盖浙江不同区域。
    • 主场优势惩罚用于避免承办地队伍获得过大优势。

    8.4 场地选择策略

    第一版可将 64 个参赛单位所在地均作为候选承办地，并用县市中心点近似位置。后续若能查到真实体育场馆数据，则将候选点替换为具体场馆。

    最终输出应包括：

    • 8 个承办地；
    • 每个承办地承办的两个小组；
    • 每支队伍到承办地的距离；
    • 总旅行距离；
    • 最大旅行距离；
    • 各地区覆盖情况；
    • 是否存在明显主场优势。

    9. 分组方案评价体系

    每个候选分组方案应输出分项指标，而不是只给一个总分。

    建议评价表如下：

    指标 含义 优化方向
    硬约束通过率 是否满足所有必须约束 必须全部通过
    同市县级队冲突数 同一市代管县级队同组次数 越小越好
    组间实力方差 各组代理实力是否均衡 越小越好
    组间影响力方差 各组人口/GDP/消费覆盖是否均衡 越小越好
    平均组内距离 同组队伍地域分散程度 适中或较大
    总旅行距离 场地安排后的总交通成本 越小越好
    最大旅行距离 最远队伍的交通负担 越小越好
    抽签熵 抽签随机性 越大越好
    同组概率偏差 抽签是否偏向特定组合 越小越好
    承办地覆盖度 赛事是否覆盖全省 越大越好

    最终推荐方案不一定每个指标都是第一，但应在关键指标上均衡，并且不被其他方案 Pareto 支配。

    10. 赛制建议

    基于上述模型，本文建议从以下方面优化赛制。

    10.1 设置合理分档

    由于浙江各市县人口、经济体量和潜在足球基础差异较大，完全随机分组可能导致某些小组过强、某些小组过弱。因此建议在抽签前设置分档。分档不应只按行政级别，还应综合人口、经济、历史足球基础或代理实力指标。

    10.2 保持行政回避规则

    市级队不与代管县级队同组可以避免行政隶属关系引发的公平争议，也能提升比赛的公开性和透明度。该约束应作为硬约束保留。

    10.3 同市县级队回避作为软约束

    同一市代管县级队完全回避在数学上可能可行，但会限制抽签随机性并增加流程复杂度。因此建议将其作为优先级很高的软约束，即尽量避免，但在必要时允许极少量冲突，并公开说明原因。

    10.4 淘汰赛路径应避免同组队过早重逢

    小组前两名进入淘汰赛后，应设计交叉对阵，使同组出线队至少在较后轮次才可能再次相遇。这可以提升淘汰赛多样性和观赏性。

    10.5 承办地应兼顾中立性和覆盖面

    若某队在本地承办地比赛，可能形成主场优势。建议优先安排相对中立的承办地，或者在模型中加入主场优势惩罚。同时，8 个承办地应尽量覆盖浙北、浙东、浙南、浙中、浙西等区域，以扩大赛事影响和普及面。

    10.6 控制旅行负担

    集中赛会制虽然便于组织，但如果承办地选择不合理，会使部分队伍旅行距离过长。因此建议将最大旅行距离作为硬性审查指标，避免出现极端不公平。

    11. 最优性说明

    本题属于组合优化问题，理论上可行分组数量巨大。如果仅凭人工经验给出分组，难以说明方案最优。因此本文采用以下方式说明方案质量：

    1. 所有输出方案必须通过硬约束检查。
    2. 使用整数规划或 CP-SAT 得到可行解，并尽量给出最优性 gap 或搜索证据。
    3. 使用多组权重生成候选方案，避免结果依赖单一主观权重。
    4. 使用局部搜索或模拟退火对候选方案继续改进。
    5. 使用 Pareto 筛选保留非支配方案。
    6. 对最终方案做多 seed 重复实验，检验稳定性。
    7. 对抽签机制做蒙特卡洛模拟，检验随机公平性。
    8. 对承办地方案计算总旅行距离、最大旅行距离和覆盖指标。

    因此，最终只能在严谨意义上表述为：

    在当前公开数据、模型假设和计算预算下，本文给出的方案是满足全部硬约束并在多目标评价下表现稳定的近优方案。

    除非求解器明确证明全局最优，否则不应直接声称“绝对最优”。

    12. 后续计算结果应补充的位置

    当前文档是总报告框架和算法说明。后续完成程序求解后，应将以下结果补入本文：

    1. 若干具体分组方案表。
    2. 各分组方案的指标对比表。
    3. 最终推荐方案。
    4. 抽签模拟结果表。
    5. 8 个承办地及其对应小组。
    6. 各队旅行距离统计。
    7. 敏感性分析图表。
    8. 最终赛制建议的定量依据。
