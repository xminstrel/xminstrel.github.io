    一、问题二的建模目标

    问题二可以抽象成：

    在合法分组方案集合中，用公开随机机制选出一个最终分组方案。

    设合法方案集合为：

    [
    \Omega={X\mid X \text{ 满足分组硬约束和行政约束}}
    ]

    其中 (X=(x_{tg})) 表示一个完整分组方案。

    你的问题一已经进一步采用了强筛选条件：

    [
    n_{ig}\leq 1,\quad \forall i,g
    ]

    所以可以定义高质量合法方案集：

    [
    \Omega^*={X\in\Omega \mid n_{ig}\leq 1,\ \text{且综合评价指标达到设定阈值}}
    ]

    问题二的核心就是设计一个抽签机制，使得：

    [
    X^\sim \text{Uniform}(\Omega^)
    ]

    也就是从高质量合法方案集中随机抽取一个方案。

    这样既保留“抽签”的随机性，又能保证抽出来的方案不会违反规则，也不会质量太差。

    二、为什么不能直接现场逐队纯随机抽签？

    最直观的方法是把 64 支队伍放进抽签箱，一个一个抽进 16 个小组。但这个方法有明显问题：

    1. 容易抽出非法分组
      例如市级队可能同组，市级队可能遇到本市代管县级队。

    2. 后抽队伍可能无合法位置
      前面随机结果不好时，后面的队伍可能没有可进入的小组，产生“死锁”。

    3. 反复重抽会降低透明性
      如果现场多次重抽，观众会怀疑是否人为控制。

    4. 不能保证较好性质
      即使合法，也可能出现实力严重不均衡、地理距离过大、观赏性差等问题。

    所以问题二不建议采用“完全无约束随机抽签”，而应采用：

    约束抽签机制，也就是“随机性 + 规则校验 + 质量筛选”。

    三、推荐方案：优质方案池公开随机抽签法

    这是最适合你当前建模框架的方案。

    1. 核心思想

    先用问题一的模型生成大量满足约束的分组方案，再用评价模型筛选出一批高质量方案，最后通过公开随机数从这批方案中抽取最终方案。

    也就是说：

    生成合法方案池
↓
计算综合评价指标
↓
筛选优质方案池
↓
公开随机抽取一个方案
↓
得到最终分组

    这比现场逐队抽签更稳，因为抽签前已经保证所有候选方案都合法且质量较高。

    四、具体抽签流程

    第 1 步：建立合法方案池

    用你问题一中的约束搜索或直接寻优方法生成 (N) 个合法方案：

    [
    \Omega_N={X_1,X_2,\dots,X_N}
    ]

    每个方案必须满足：

    [
    \sum_{t\in T}x_{tg}=4,\quad \forall g
    ]

    [
    \sum_{g=1}^{16}x_{tg}=1,\quad \forall t
    ]

    [
    \sum_{t\in M}x_{tg}\leq 1,\quad \forall g
    ]

    [
    x_{m_i g}+x_{cg}\leq 1,\quad \forall i,\forall c\in C_i,\forall g
    ]

    并且优先满足：

    [
    n_{ig}\leq 1,\quad \forall i,g
    ]

    这正好和你当前问题一的生成规则一致。你的文档中已经说明，候选池评价法是随机化约束搜索生成满足硬约束和同市县级队不重复条件的候选方案，再用 TOPSIS 排序；直接寻优法是在可行域内用模拟退火优化综合目标。

    第 2 步：计算每个方案的综合评价指标

    对每个方案 (X_k) 计算问题一中的指标，例如：

    指标 方向
    小组实力方差 (F_{\text{sport}}) 越小越好
    实力极差 (F_{\text{range}}) 越小越好
    竞争悬念 (Q_{\text{comp}}) 越大越好
    热点对决指数 (H_{\text{match}}) 越大越好
    经济均衡性 (B_{\text{eco}}) 越小越好
    人口均衡性 (B_{\text{pop}}) 越小越好
    文旅均衡性 (B_{\text{tour}}) 越小越好
    平均组内距离 (D_{\text{avg}}) 越小越好
    地域覆盖度 (G_{\text{cover}}) 越大越好

    你当前文档中已经建立了 AHP-熵权组合赋权和 TOPSIS 排序模型，因此可以直接沿用该综合评价体系。

    第 3 步：筛选优质方案池

    从全部合法方案池 (\Omega_N) 中筛选出优质方案池：

    [
    \Omega^*={X_k\in\Omega_N\mid C_k\geq C_0}
    ]

    其中：

    • (C_k) 是 TOPSIS 贴近度；

    • (C_0) 是阈值。

    阈值可以有几种设置方式：

    筛选方式 例子 特点
    前 (K) 个方案 取 TOPSIS 前 100 个 简单直接
    前 (q%) 方案 取前 10% 或 20% 保留更多随机性
    指标阈值法 实力方差、距离、CV 均不超过阈值 更可解释
    综合法 先设硬阈值，再取前 (K) 最稳妥

    建议采用：

    [
    \Omega^*={X_k\mid C_k \text{ 排名前 } 20%}
    ]

    或者：

    [
    \Omega^*={X_k\mid F_{\text{sport}}\leq \tau_1,\ D_{\text{avg}}\leq \tau_2,\ C_k\geq \tau_3}
    ]

    这样抽签得到的方案既有随机性，又不会太差。

    第 4 步：公开冻结方案池

    为了防止“抽签前后替换方案池”，需要把方案池公开冻结。

    具体做法：

    1. 将优质方案池保存为表格：

      scheme_pool.csv

    2. 每个方案编号：

      P0001, P0002, ..., PK

    3. 按编号排序。

    4. 计算文件哈希值，例如：

    [
    Hash=\operatorname{SHA 256}(\text{scheme_pool.csv})
    ]

    1. 在抽签前公开：

      • 方案池文件；

      • 方案数量 (K)；

      • 哈希值；

      • 抽签规则；

      • 评价指标和阈值。

    这样可以保证抽签过程不能临时改方案。

    第 5 步：公开随机抽取方案编号

    现场生成一个随机整数 (R)。

    例如可以使用 10 个数字球，依次抽出组成一个大整数：

    [
    R=7392048615
    ]

    若优质方案池中共有 (K) 个方案，则最终方案编号为：

    [
    q=(R\bmod K)+1
    ]

    最终选取：

    [
    X^*=X_q
    ]

    例如，如果 (K=100)，则：

    [
    q=(7392048615\bmod 100)+1=16
    ]

    则选择编号为 P0016 的方案。

    五、该方案的可行性证明

    1. 合法性

    因为：

    [
    \Omega^*\subseteq \Omega
    ]

    而 (\Omega) 中每个方案都满足：

    [
    \sum_{t\in T}x_{tg}=4
    ]

    [
    \sum_{g=1}^{16}x_{tg}=1
    ]

    [
    \sum_{t\in M}x_{tg}\leq 1
    ]

    [
    x_{m_i g}+x_{cg}\leq 1
    ]

    [
    n_{ig}\leq 1
    ]

    所以从 (\Omega^) 中抽出的任意方案 (X^) 都必然满足题目要求。

    2. 随机公平性

    如果随机数 (R) 是公开产生的，且 (R\bmod K) 在 (0,1,\dots,K-1) 上近似均匀，则每个优质方案被抽中的概率为：

    [
    P(X_k)=\frac{1}{K},\quad X_k\in\Omega^*
    ]

    因此，抽签过程对优质方案池内的每个方案是等概率的。

    3. 透明性

    透明性来自三点：

    1. 方案池提前公开；

    2. 方案池哈希提前公开；

    3. 随机数现场公开产生。

    这样可以避免人为指定某个方案。

    4. 较好性质

    因为 (\Omega^*) 是从高质量方案中筛选得到的，任意抽出的方案都满足：

    [
    C_k\geq C_0
    ]

    或者满足设定的指标阈值，例如：

    [
    F_{\text{sport}}\leq \tau_1
    ]

    [
    D_{\text{avg}}\leq \tau_2
    ]

    [
    B_{\text{pop}}\leq \tau_3
    ]

    所以抽签结果不仅合法，而且在竞技公平性、观赏性、经济人口文旅均衡性和地理合理性上具有基本保证。

    六、这个方案的优点和缺点

    适用条件

    适用于：

    • 已经建立问题一的候选方案生成模型；

    • 已经有综合评价指标；

    • 希望抽签过程可控、透明、可复现；

    • 希望避免现场抽签死锁。

    核心思想

    把“逐队抽签”转化为“从合法优质方案集中抽取完整方案”。

    需要的数据

    • 参赛队伍名单；

    • 行政隶属关系；

    • 问题一的候选方案池；

    • 综合评价指标；

    • 方案池编号；

    • 公开随机数。

    优点

    1. 不会抽出非法方案
      因为方案池中的每个方案已经通过约束检验。

    2. 没有死锁问题
      不存在抽到一半无合法位置的情况。

    3. 兼顾公平和质量
      在高质量方案池中等概率抽取。

    4. 和问题一模型衔接自然
      你已经有 TOPSIS 和直接寻优结果，可以直接作为方案池基础。

    5. 方便论文表达
      可以写成“约束生成—质量筛选—公开随机抽取”的完整机制。

    缺点

    1. 不是对所有合法方案等概率抽取
      它是对优质方案池等概率抽取。

    2. 方案池生成算法需要公开
      否则会被质疑方案池是人为挑选的。

    3. 方案池规模会影响公平性
      如果只放 5 个方案，随机性较弱；如果放 500 或 1000 个方案，公平性更强。

    改进方向

    • 增大优质方案池规模；

    • 公布候选池生成代码和随机种子；

    • 对方案池进行多样性筛选，避免方案过于相似；

    • 设置多个质量阈值而不是只看 TOPSIS 得分。

    七、备选方案：三阶段现场约束抽签法

    如果你希望抽签形式更接近传统赛事抽签，可以设计一个“三阶段抽签法”。

    阶段 1：抽市级队所在小组

    准备 16 个小组球：

    [
    G 01,G 02,\dots,G 16
    ]

    准备 11 个市级队球：

    [
    m_1,m_2,\dots,m_{11}
    ]

    依次抽取市级队和小组，将 11 个市级队放入 11 个不同小组。

    抽完后，有：

    • 11 个小组含 1 支市级队；

    • 5 个小组暂时没有市级队。

    这满足：

    [
    \sum_{t\in M}x_{tg}\leq 1
    ]

    阶段 2：抽城市分布模板

    设第 (i) 个市的县级队数量为：

    [
    r_i=|C_i|
    ]

    设第 (i) 个市级队被抽到的小组为：

    [
    h_i
    ]

    定义城市分布模板变量：

    [
    a_{ig}=
    \begin{cases}
    1, & \text{第 }i\text{ 个市有 1 支县级队进入第 }g\text{ 组}\
    0, & \text{否则}
    \end{cases}
    ]

    模板需要满足：

    [
    \sum_g a_{ig}=r_i,\quad \forall i
    ]

    [
    \sum_i a_{ig}=4-b_g,\quad \forall g
    ]

    其中：

    [
    b_g=
    \begin{cases}
    1, & \text{第 }g\text{ 组已有市级队}\
    0, & \text{否则}
    \end{cases}
    ]

    并且：

    [
    a_{i,h_i}=0,\quad \forall i
    ]

    表示本市县级队不能进入本市市级队所在小组。

    再加入强筛选条件：

    [
    a_{ig}\in{0,1}
    ]

    这保证同一市代管县级队在任一小组中最多出现 1 支。

    然后从所有可行模板中随机抽取一个模板。

    阶段 3：抽具体县级队

    对于每个市 (i)，模板已经确定了该市县级队要进入哪些小组：

    [
    G_i^*={g\mid a_{ig}=1}
    ]

    然后将该市的县级队 (C_i) 随机打乱，依次填入这些小组。

    例如温州有 8 支县级队，模板确定温州县级队进入 8 个不同小组，那么现场只需要把温州的 8 个县级队随机抽入这 8 个小组。

    八、三阶段抽签法的特点

    优点

    1. 更接近传统抽签；

    2. 每一步都可以现场展示；

    3. 市级队位置随机；

    4. 县级队分布由模板保证合法；

    5. 不会出现同市县级队重复同组；

    6. 不会出现市级队与本市县级队同组。

    缺点

    1. 需要计算机提前生成可行模板；

    2. 如果只随机模板，不加入综合评价，方案质量不一定最优；

    3. 模板抽签对普通观众理解略复杂；

    4. 不如“优质方案池抽签法”容易保证竞技、经济、地理等综合指标。

    九、两种方案对比

    方案 合法性 透明性 随机性 综合质量 现场操作难度 推荐程度
    逐队纯随机抽签 低 高 高 不稳定 低 不推荐
    动态约束逐队抽签 较高 中等 中等 不稳定 中等 可作为说明
    三阶段现场约束抽签 高 高 高 中等 中等偏高 备选
    优质方案池公开抽签 最高 高 高 高 低 最推荐

    十、我建议你论文里采用的主方案

    建议问题二采用：

    优质方案池公开随机抽签法

    并把三阶段现场约束抽签法作为备选方案或现实执行方式。

    论文主线可以这样写：

    问题一已经建立了满足行政约束的分组模型，并从竞技公平性、观赏性、经济人口文旅均衡性和地理合理性等方面对方案进行综合评价。因此，问题二不再采用无约束逐队抽签，而是设计“优质方案池公开随机抽签法”。该方法先生成满足所有分组约束的方案池，再根据综合评价指标筛选出优质方案集，最后通过公开随机数从优质方案集中等概率抽取最终分组方案。该方法能够同时保证合法性、透明性和方案质量。

    十一、可直接写进论文的抽签算法

    可以写成如下算法。

    算法：优质方案池公开随机抽签法

    输入：

    [
    T,G,M,C_i,R_t,A_t,d_{ab}
    ]

    输出：最终分组方案 (X^*)。

    步骤：

    1. 根据题目约束生成候选方案池 (\Omega_N)；

    2. 对每个方案 (X_k\in\Omega_N) 计算综合评价指标；

    3. 利用 TOPSIS 或直接目标函数得到方案得分 (C_k)；

    4. 设定筛选阈值 (C_0)，得到优质方案集：

    [
    \Omega^*={X_k\in\Omega_N\mid C_k\geq C_0}
    ]

    1. 将 (\Omega^*) 中方案按编号排序；

    2. 公开方案池、评价指标、筛选阈值和文件哈希；

    3. 现场抽取公开随机整数 (R)；

    4. 计算：

    [
    q=(R\bmod |\Omega^*|)+1
    ]

    1. 输出第 (q) 个方案作为最终分组方案。

    十二、和你当前 D 001 方案的关系

    你当前问题一推荐 D 001，是因为它在直接寻优模型下综合表现较好。你的文档中也指出，D 001 在实力方差、实力极差、竞争悬念等方面优于候选池代表方案 S 0390，并被作为当前建模口径下的主推荐方案。

    但问题二强调“抽签”，所以不要写成：

    直接指定 D 001 为抽签结果。

    更合理的写法是：

    将 D 001 及其若干质量接近的备选方案 D 002-D 005，连同候选池中 TOPSIS 排名前列方案，共同构成优质方案池；最终通过公开随机数从优质方案池中抽取一个方案。若抽中 D 001，则采用 D 001；若抽中其他优质方案，也能保证满足约束并具有较好性质。

    这样既尊重“抽签”原则，又利用了你问题一的优化结果。

    十三、最终建议表述

    你可以在论文问题二最后这样总结：

    本文设计了基于优质方案池的公开随机抽签机制。首先利用问题一建立的约束模型生成满足赛事规则的合法分组方案，并采用同市县级队不重复同组的强化筛选条件；其次，根据竞技公平性、观赏性、经济人口文旅均衡性和地理合理性等指标对候选方案进行评价，筛选得到优质方案集；最后，通过现场公开随机数按模运算确定最终方案编号。该方法能够保证抽签结果必然满足分组约束，同时避免传统逐队抽签可能出现的死锁和反复重抽问题，并能使最终方案在综合评价指标上保持较好水平。
