    横纵prompt

    约 0 字 约 1 分钟 
    请使用“横纵分析法”研究以下对象：

研究对象 = 【在这里填写你要研究的对象】

请从三个部分展开：

一、纵向分析：它是怎么发展到今天的？
1. 它出现之前，相关领域存在什么问题？
2. 它诞生的背景、时间、核心推动者是谁？
3. 它从诞生到现在经历了哪些关键阶段？
4. 每个关键阶段背后的技术、商业或社会原因是什么？
5. 它过去的重要选择如何影响了今天的形态？

二、横向分析：它现在处在什么位置？
1. 它的同类对象、竞品或替代方案有哪些？
2. 它和这些对象相比，核心差异是什么？
3. 它的优势、短板、适用场景和不适用场景分别是什么？
4. 用户或行业为什么选择它？
5. 它在整个生态或赛道中占据什么位置？

三、横纵交汇：形成综合判断
1. 它今天的优势来自过去哪些积累？
2. 它今天的问题来自过去哪些限制？
3. 它未来可能的发展方向是什么？
4. 它面临的最大机会和风险是什么？
5. 如果我是初学者/研究者/从业者，应该如何理解和使用它？

要求：
- 不要只罗列时间线，要解释因果关系。
- 不要只做参数对比，要解释真实使用场景。
- 所有关键事实尽量标注来源。
- 不确定的信息请明确说明，不要编造。
- 最后给出一份适合初学者的学习建议或行动路线。
