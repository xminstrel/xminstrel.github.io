# 问题 1  分组方案
## 思路
**采用 0-1 整数规划模型 + 多指标评价模型**

| 约束类型  | 题目要求            | 建模处理       |
| ----- | --------------- | ---------- |
| 硬约束 1 | 每组 4 队          | 必须严格满足     |
| 硬约束 2 | 每队只能进入一个组       | 必须严格满足     |
| 硬约束 3 | 11 个市级队应分配在不同小组 | 必须严格满足     |
| 硬约束 4 | 市级队不与其代管县级队同组   | 必须严格满足     |
| 软约束   | 同一市代管县级队尽量不同组   | 可转化为惩罚项最小化 |
其他指标



符号定义：

| $符号$       | $含义$                        |
| ---------- | --------------------------- |
| $(T)$      | $全部参赛队伍集合，共 64 支$           |
| $(G)$      | $小组集合，(G={1,2,\dots,16})$   |
| $(M)$      | $市级队集合，共 11 支$              |
| $(C_i)$    | $第 (i) 个市代管的县级队集合$          |
| $(m_i)$    | $第 (i) 个市的市级队$              |
| $(x_{tg})$ | $队伍 (t) 是否分到小组 (g)$         |
| $(n_{ig})$ | $第 (i) 个市的县级队在小组 (g) 中的数量$  |
| $(u_{ig})$ | $第 (i) 个市在小组 (g) 中的县级队重复惩罚$ |

决策变量：
$$x_{tg} = \begin{cases} 1, & \text{队伍 } t \text{ 被分到第 } g \text{ 组} \\ 0, & \text{否则} \end{cases}$$

**硬约束 1：**
每组 4 队  
$$\sum_{t\in T}x_{tg}=4,\quad\forall g\in G$$

**硬约束 2：**
每队只能进入一个组
$$\sum_{g=1}^{16}x_{tg}=1,\quad\forall t\in T$$
**硬约束 3：**
11 个市级队应分配在不同小组
$$\sum_{t\in M}x_{tg}\leq1,\quad\forall g\in G$$

**硬约束 4：**
市级队不与其代管县级队同组

$对每个市 (i)，其市级队为 (m_i)，代管县级队集合为 (C_i)。$
$对任意县级队 (c\in C_i)，有：$
$$
x_{m_i g}+x_{cg}\leq 1,\quad \forall i,\forall c\in C_i,\forall g\in G 
$$

**软约束：**
尽量不内战
同一市代管县的县级队应尽量不分配在同一小组

量化定义：
$$n_{ig}=\sum_{c\in C_i}x_{cg}$$
表示第 i个市的县级队在第 g个小组中有几支。

如果 $n_{ig}=0  或  n_{ig}=1$ ，说明没有同市县级队重复。

如果 $n_{ig}=2$，说明该小组中有两支同市县级队。

如果 $n_{ig}=3$ ，说明重复更严重。

定义重复惩罚：
$$
u_{ig​}=max(0,n_{ig}​−1)
$$
目标函数
$$总行政重复冲突minZ_1=C_1 = \sum_{i=1}^{11} \sum_{g=1}^{16} u_{ig}$$






!!! tip "think"
	根据约束条件，穷举出所有满足硬约束要求的分组方案，如果多的话考虑软约束简化，然后根据这些分组的方案，引入经济实力，人口、文旅等因素，建立评价模型，对分组方案进行评价，或者建立雷达图？，对方案进行编号优先级排序

分析一下纯用硬约束有多少方案，有点多
在强筛选条件下，理论上有多少个方案？

在下面这个标准化设定下：

- G 01-G 11 分别固定放入 11 个市级队；
- G 12-G 16 为 5 个无市级队小组；
- 每组 4 队；
- 市级队不与本市县级队同组；
- 同一市代管县级队在任一小组中最多出现 1 支；
- 县级队视为不同个体；
- G 01-G 16 视为有标签小组；

固定市级队后，只需要分配 53 支县级队。

11 个含市级队的小组各剩 3 个名额，5 个无市级队小组各有 4 个名额，所以剩余容量为：

(3,3,…,3,4,4,4,4,4)

前 11 个小组容量为 3，后 5 个小组容量为 4。

各市代管县级队数量为：

(3,4,8,5,3,3,7,4,2,6,8)

先统计“每个市的县级队被放到哪些小组”的 0-1 矩阵数量。这个矩阵需要满足：

1. 第 i行和为该市县级队数量；
2. 第 g 列和为该小组剩余容量；
3. 对角线为 0，即本市县级队不能进入本市市级队所在组；
4. 每个位置只能是 0 或 1，即同市县级队不能在同一组重复出现。

### 评价指标
接下来建立评价指标进一步筛选
由于已经筛选同一市代管县级队在任一小组中最多出现 1 支，所以不把行政公平性作为指标
但是可以写成：方案可行性与行政公平性检验

| 一级指标   | 二级指标                        | 方向   | 是否必须 |
| ------ | --------------------------- | ---- | ---- |
| 合规性    | $硬约束违反数$                    | =0   | 必须   |
| 行政公平性  | $同市县级队重复指数 (E_1)$           | 越小越好 | 必须   |
| 行政公平性  | $成对冲突指数 (E_2)$              | 越小越好 | 必须   |
| 行政公平性  | $行政来源多样性 (E_3)$             | 越大越好 | 推荐   |
| 竞技公平性  | $小组实力方差 (F_{\text{sport}})$ | 越小越好 | 推荐   |
| 竞技公平性  | $死亡之组惩罚 (F_{\max})$         | 越小越好 | 推荐   |
| 观赏性    | $小组竞争悬念 (Q_{\text{comp}})$  | 越大越好 | 推荐   |
| 观赏性    | $热点对决指数 (H_{\text{match}})$ | 越大越好 | 可选   |
| 经济人口文旅 | $经济均衡性 (B_{\text{eco}})$    | 越小越好 | 可选   |
| 经济人口文旅 | $人口均衡性 (B_{\text{pop}})$    | 越小越好 | 可选   |
| 经济人口文旅 | $文旅均衡性 (B_{\text{tour}})$   | 越小越好 | 可选   |
| 地理合理性  | $组内平均距离 (D_{\text{avg}})$   | 越小越好 | 推荐   |
| 地理合理性  | $地域覆盖度 (G_{\text{cover}})$  | 越大越好 | 可选   |
| 稳定性    | $权重扰动下排名稳定性$                | 越高越好 | 推荐   |


#### 竞技公平性指标
##### 1 . 体育实力分

$$R_t^{\text{base}} = 100 \left( 0.35 F_t' + 0.25 Y_t' + 0.20 I_t' + 0.10 P_t' + 0.10 E_t' \right)$$

| 指标             |   权重 | 解释                |
| -------------- | ---: | ----------------- |
| $足球基础设施 (F_t')$  | 0.35 | 足球场地、训练条件直接影响参赛基础 |
| $青训与校园足球 (Y_t')$ | 0.25 | 反映后备人才和群众足球基础     |
| $体育资源投入 (I_t')$  | 0.20 | 反映体育组织和保障能力       |
| $人口基础 (P_t')$    | 0.10 | 反映人才池规模           |
| $经济支撑 (E_t')$    | 0.10 | 反映潜在保障能力          |
由于缺少各参赛队真实历史交锋数据，本文将 $R_t$ 定义为潜在体育实力指数，而非真实竞技实力。该指数综合考虑足球基础设施、青训与校园足球基础、体育资源投入、人口基础和经济支撑能力，用于近似衡量各地区组织高水平参赛队伍的潜力。



##### 2. 小组实力均衡性
第 g 组总实力：
$$S_g = \sum_{t \in g} R_t$$
方案的组间实力方差：
$$F_{\text{sport}} = Var(S_1, S_2, \dots, S_{16})$$
方向：**越小越好**

也可以用变异系数：
$$CV_{\text{sport}} = \frac{\text{Std}(S_1, \dots, S_{16})}{\text{Mean}(S_1, \dots, S_{16})}$$
方向：**越小越好**。

含义：

> 各小组整体实力越接近，分组越公平。


##### 3 . 死亡之组惩罚

$$F_{\text{range}} = \max_{g} S_g - \min_{g} S_g$$
越小越好，避免出现某个小组明显强于其他小组

总体方案
```
生成候选方案池
↓
硬约束检验，剔除非法方案
↓
计算行政公平性指标
↓
引入体育、经济、人口、文旅、地理数据
↓
计算每个方案的多维评价指标
↓
对指标进行正向化和标准化
↓
用熵权法或 AHP-熵权组合确定权重
↓
用 TOPSIS 计算综合得分
↓
对方案编号排序
↓
选出最优方案和若干备选方案
↓
做权重灵敏度分析
```
