# B 题资料与研究路线简报

## 题目本质

“浙超”分组不是单一随机分组问题，而是四个相互耦合的问题：

1. 约束分组：64 队分入 16 组，每组 4 队，并满足市级队分散、市级队回避代管县级队等硬约束。
2. 公平抽签：设计可公开执行的随机机制，使抽签过程既透明又尽量接近公平随机。
3. 承办地选择：选 8 个地点，每地承办 2 组，兼顾旅行成本、覆盖面、影响力和主场优势。
4. 赛制建议：基于模拟和优化结果讨论分档、淘汰赛路径、赛程公平等规则。

## 已有资料

- 题面 PDF：硬约束和参赛单位来自题面。
- 浙江统计年鉴：已获得县市层面人口、GDP、财政、消费、收入等代理指标。
- 行政区划资料：用于校验县市归属和名称。
- 体育场地资料：已列入资料登记，后续需按候选承办地逐项查证。
- 运筹文献：约束抽签、体育赛程优化、旅行公平和设施选址是本题的主要理论支撑。

## 数据如何进入模型

| 数据 | 用途 | 风险 |
|---|---|---|
| 题面参赛单位与归属关系 | 硬约束 | 不可更改 |
| 人口、GDP、消费、财政、收入 | 实力/影响力代理指标 | 不等于球队真实实力 |
| 经纬度/地图路径时间 | 地理分散和旅行成本 | 距离不等于真实通行时间 |
| 场馆容量与交通 | 承办地能力 | 需要逐项查证 |
| 赛事/足球基础数据 | 竞技实力代理 | 公开数据可能不完整 |

## 推荐数学方法

1. CP-SAT 或整数规划：作为核心分组与场地选择模型，负责硬约束和多目标优化。
2. 图论：把“不能同组”和“尽量不同组”看成冲突图，分组是带容量的图划分/着色问题。
3. 多目标优化：生成公平型、地理型、影响力型和综合型方案，并比较 Pareto 前沿。
4. 蒙特卡洛模拟：审计抽签机制是否偏向某些队伍或组合。
5. p-median / p-center：解决 8 个承办地选择与旅行公平问题。
6. 敏感性分析：证明最终建议不依赖单一权重或单一代理指标。

## 最强论文主线

建议论文主线写成：

> 本文将“浙超”分组问题建模为带硬约束和多目标软偏好的组合优化问题。首先基于行政隶属关系建立冲突图和 0-1 规划模型，生成多个满足硬约束的候选分组方案；再从属地回避、实力均衡、地理分散、影响力覆盖等维度构造评价体系，筛选 Pareto 最优方案。随后设计可公开执行的“分档随机 + 在线可行性检查”抽签流程，并通过蒙特卡洛模拟检验随机公平性。最后将承办地选择建模为带容量约束的设施选址问题，综合旅行成本、空间覆盖和赛事影响力选择 8 个承办地，并据此提出赛制改进建议。

## 下一轮最值得做的事

1. 建立队伍数据加载与硬约束检查器。
2. 给 64 个单位补经纬度，先用城市/县政府驻地作为代表点。
3. 构造 baseline 可行分组。
4. 加入年鉴数据的实力/影响力代理指标。
5. 运行多权重优化，比较至少 4 类方案。
6. 对抽签机制做 10000 次模拟，输出偏差审计表。
