# B 题数学建模框架

## 1. 集合与变量

- 参赛队集合 `T`，共 64 支。
- 市级队集合 `C`，共 11 支。
- 县级队集合 `K`，共 53 支。
- 小组集合 `G={1,...,16}`，每组容量 4。
- 候选承办地集合 `V`，后续由 64 个参赛单位或筛选后的可承办场馆生成。

分组变量：

- `x[t,g] in {0,1}`：队伍 `t` 是否进入小组 `g`。

场地变量：

- `z[v] in {0,1}`：地点 `v` 是否被选为承办地。
- `a[g,v] in {0,1}`：小组 `g` 是否分配到承办地 `v`。

## 2. 硬约束

1. 每队恰好进入一个小组：
   `sum_g x[t,g] = 1`。
2. 每组恰好 4 支队伍：
   `sum_t x[t,g] = 4`。
3. 市级队分散：
   `sum_{t in C} x[t,g] <= 1`。
4. 市级队与其代管县级队不同组：
   对任意市级队 `c` 及其县级队 `k`，`x[c,g] + x[k,g] <= 1`。
5. 选 8 个承办地：
   `sum_v z[v] = 8`。
6. 每个承办地承办 2 个小组：
   `sum_g a[g,v] = 2 z[v]`。
7. 每组恰好分配一个承办地：
   `sum_v a[g,v] = 1`。

## 3. 软约束与评价指标

分组层指标：

- `same_parent_conflict`：同一市代管县级队同组的冲突数，越小越好。
- `region_dispersion`：同组队伍地理距离均值或最小距离，视目标可最大化分散度。
- `strength_balance`：组内实力代理指标总和的方差，越小越公平。
- `visibility_balance`：各组人口/GDP/消费影响力代理指标方差，越小表示关注度更均衡。
- `derby_value`：适量保留跨市邻近对抗或强队碰撞的观赏性，但不能破坏公平。

抽签层指标：

- `feasibility_rate`：随机流程中满足硬约束的比例。
- `draw_entropy`：队伍落入不同小组的边际分布熵。
- `pair_bias`：任意两队同组概率与理想概率的偏差。
- `explainability`：抽签步骤是否可由人工监督执行，是否易于公布。

场地层指标：

- `travel_cost`：队伍到承办地的总距离/时间。
- `max_travel`：最远队伍旅行负担，控制极端不公平。
- `venue_coverage`：8 个承办地在浙江省空间上的覆盖面。
- `host_advantage`：承办地队伍在本地比赛的优势，需要约束或纳入惩罚。
- `impact_score`：人口、GDP、交通枢纽、场馆容量和地区均衡的综合影响力。

## 4. 算法路线

### A. 可行分组生成

先用 CP-SAT 或 ILP 求满足硬约束的分组。目标函数先最小化同属地县级队冲突，再加入实力均衡、地理分散、影响力均衡等软目标。

### B. 多目标优化

用多组权重生成候选 Pareto 解，再用敏感性分析检验方案是否依赖特定权重。若精确模型求解慢，用局部搜索、模拟退火或遗传算法做大规模搜索，再由约束检查器过滤。

### C. 抽签机制

设计“分档 + 受限随机 + 回溯修正”的透明流程：

1. 市级队先独立抽入 11 个不同小组，其余 5 组为空市级组。
2. 县级队按所属市、实力代理或地理区块分档。
3. 逐档抽签，每次只允许放入当前仍可扩展到完整可行解的位置。
4. 抽签后运行合规检查和偏差审计；用蒙特卡洛模拟估计不同队伍落组概率。

### D. 场地选择

将承办地问题建成带容量约束的 p-median / p-center 混合模型：

- 选 8 个点；
- 每点承办 2 组；
- 最小化总旅行成本和最大旅行成本；
- 同时加入区域覆盖、承办能力和影响力分数；
- 必要时限制本地队伍不在本地承办地比赛，降低主场优势。

### E. 赛制建议

基于模型结果分析：

- 4 队小组单循环是否足以降低偶然性；
- 是否应设置分档或种子队；
- 小组出线与淘汰赛对阵路径是否应回避同组队过早重逢；
- 是否需要主客/中立场、赛程休息天、同城回避等规则。

## 5. 最优性判据

不能只说“已经很好”，需要用以下证据说明难以继续精进：

- 硬约束全部通过自动检查。
- 精确求解器给出最优解或较小 gap；若无全局最优证明，给出下界/上界和搜索停止理由。
- 多 seed、不同初值、不同权重下候选方案稳定。
- Pareto 前沿上最终方案不是被其他方案支配的解。
- 对关键代理指标权重做敏感性分析，结论不因单一权重选择而倒塌。
- 抽签机制经大量模拟后偏差可解释、可公布、可复现。
