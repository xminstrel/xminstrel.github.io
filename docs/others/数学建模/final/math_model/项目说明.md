# 浙江省市县足球联赛分组建模

这是一个整理后的自包含数学建模工程，用来解决浙江省 64 支市县足球队的分组、公开抽签、赛地选择和赛制建议问题。

项目只保留三类东西：

- 输入数据：`data/`
- 可复现代码：`src/`、`scripts/`、`tests/`
- 最终结果：`results/`

人读文档只保留 3 个：

- `项目说明.md`：项目入口说明。
- `项目总结.md`：完整说明问题、模型、算法、验证和结果。
- `results/结果汇总.md`：所有运行结果的统一汇总。

## 快速运行

```powershell
cd D:\desktop\math_model
python scripts\run_all.py --starts 80 --steps 400 --lottery-candidates 300 --sims 1000
python -m pytest -q
```

## 最终结论

- 行政冲突图：64 点、232 边，11 色构造成功。
- 问题一：最终推荐 D003。
- 问题二：采用优质方案池公开哈希抽签。
- 问题三：推荐赛地为台州市、宁波市、杭州市、温州市、绍兴市、金华市、青田县、龙游县。
- 问题四：推荐 16 组单循环、小组前二晋级、32 强单败淘汰。
