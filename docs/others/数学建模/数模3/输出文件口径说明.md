# 输出文件口径说明

数模3 中保留了若干中间运行结果。最终论文和最终方案应使用以下文件：

| 用途 | 最终文件 |
|---|---|
| 融合数据 | `data/final_teams.csv` |
| 图染色分析 | `outputs_graph/graph_coloring_analysis.md` |
| 问题一最终分组选择 | `outputs_selection/问题一方案选择说明.md` |
| 问题一最终分组 CSV | `outputs_selection/selected_scheme.csv` |
| 问题二抽签池和抽签结果 | `outputs_lottery/final_draw_scheme.md` |
| 问题三赛地结果 | `outputs_venues_selected/venue_solution.md` |
| 问题四赛制仿真 | `outputs_tournament_selected/simulation_summary.md` |
| 总方案文档 | `建模总方案.md` |

以下文件为中间结果或早期结果，不作为最终结论直接引用：

| 文件或目录 | 说明 |
|---|---|
| `outputs_direct/direct_best_scheme.csv` | 直接搜索目标最高的 D001，不是最终 TOPSIS 推荐分组 |
| `outputs_direct/direct_top_schemes.md` | D001-D005 候选方案比较，需结合 `outputs_selection` 使用 |
| `outputs_venues/` | 基于早期 D001 的赛地结果，已被 `outputs_venues_selected/` 替代 |
| `outputs_tournament/` | 基于早期 D001 赛地结果的仿真，已被 `outputs_tournament_selected/` 替代 |

最终口径为：问题一推荐 D003；问题三和问题四均基于 D003 重新计算。
