# 融合采用建议

## 推荐取舍

最终版本建议以当前方案为主体，不建议直接采用单一的 `数模1` 或 `数模2`。

`数模1` 的主要价值在于资料可信度和建模规范。它已经整理了题面队伍表、浙江统计年鉴数据、资料登记表和形式化建模框架，适合放入论文的数据来源、符号说明和模型假设部分。但它缺少完整优化程序和最终结果，不适合作为唯一提交方案。

`数模2` 的主要价值在于叙述完整和容易读。图染色解释、16 组设置理由、场次计算和赛制说明都可以改写进正文。但它缺少可复现代码和定量验证，不适合作为最终实证依据。

当前方案的主要价值在于四问已经跑通：问题一有多组分组方案与指标比较，问题二有方案池哈希抽签，问题三有选址和距离指标，问题四有赛制仿真。因此它应作为最终结果来源。

## 建议整合顺序

1. 先保留当前方案的输出结果，不重做整体模型。
2. 将 `数模1` 的官方统计年鉴数据和资料登记表补入论文“数据来源”部分。
3. 用 `数模2` 的图染色叙述解释行政冲突约束和 16 组的必要性。
4. 在问题一结果中保留 D001-D005 的候选方案对比，但最终推荐按 AHP-熵权-TOPSIS 综合评价选择 D003，而不是按直接搜索目标选择 D001。
5. 在问题二中明确：抽签是在优质方案池内等概率，不是对所有合法方案等概率。
6. 在问题三中说明距离和承办能力是代理计算，若有真实场馆数据可替换。
7. 在问题四中保留蒙特卡洛仿真结论，并补充同组末轮同时开赛、裁判异地派遣、淘汰赛约束对阵等制度建议。

## 可直接写入论文的综合判断

三种方案各有侧重。方案一重视数据来源和模型规范，适合保证论文的可信度；方案二重视规则解释和报告完整性，适合提升可读性；当前方案重视算法实现和定量比较，能够直接支撑最终结论。综合考虑，本研究采用当前方案作为计算主线，并吸收方案一的数据规范和方案二的表达结构，形成“数据可追溯、模型可解释、结果可复现、过程可审计”的综合方案。
