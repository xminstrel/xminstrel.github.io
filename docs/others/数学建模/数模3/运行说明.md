# 数模3运行说明

以下命令均在仓库根目录 `D:\xminblog\docs\others\数学建模` 下运行。

## 1. 生成融合数据和图染色分析

```powershell
python .\数模3\build_enriched_data_and_graph.py
```

输出：

- `数模3/data/final_teams.csv`
- `数模3/data/data_sources.csv`
- `数模3/data/数据来源与融合说明.md`
- `数模3/outputs_graph/graph_coloring_analysis.md`
- `数模3/outputs_graph/eleven_color_witness.csv`

## 2. 分组直接寻优

```powershell
python .\分组评价模型\direct_optimizer.py --teams .\数模3\data\final_teams.csv --starts 80 --steps 6000 --keep 5 --seed 2026 --initial-pool 160 --output-dir .\数模3\outputs_direct
```

输出：

- `数模3/outputs_direct/direct_top_schemes.md`
- `数模3/outputs_direct/direct_best_scheme.csv`
- `数模3/outputs_direct/direct_ranking.csv`

## 3. 公开方案池抽签

```powershell
python .\分组评价模型\lottery_draw.py --teams .\数模3\data\final_teams.csv --candidates 3000 --top-k 100 --seed 2026 --alpha 0.5 --draw-seed 7392048615 --output-dir .\数模3\outputs_lottery
```

输出：

- `数模3/outputs_lottery/scheme_pool.csv`
- `数模3/outputs_lottery/scheme_pool.sha256`
- `数模3/outputs_lottery/final_draw_scheme.md`
- `数模3/outputs_lottery/draw_record.json`

## 4. 选择问题一最终分组

```powershell
python .\数模3\select_final_group_scheme.py
```

输出：

- `数模3/outputs_selection/问题一方案选择说明.md`
- `数模3/outputs_selection/selected_scheme.csv`
- `数模3/outputs_selection/scheme_selection_table.csv`

该步骤以 TOPSIS 综合评价最高为准，最终选择 D003。

## 5. 比赛地点选择

```powershell
python .\分组评价模型\venue_selector.py --teams .\数模3\data\final_teams.csv --groups .\数模3\outputs_selection\selected_scheme.csv --output-dir .\数模3\outputs_venues_selected --max-candidates 30 --seed 2026 --iterations 8000 --profile balanced
```

输出：

- `数模3/outputs_venues_selected/venue_solution.md`
- `数模3/outputs_venues_selected/venue_assignment.csv`
- `数模3/outputs_venues_selected/venue_metrics.json`

## 6. 赛制仿真

```powershell
python .\分组评价模型\tournament_simulator.py --teams .\数模3\data\final_teams.csv --groups .\数模3\outputs_selection\selected_scheme.csv --venues .\数模3\outputs_venues_selected\venue_assignment.csv --sims 3000 --seed 2026 --output-dir .\数模3\outputs_tournament_selected
```

输出：

- `数模3/outputs_tournament_selected/simulation_summary.md`
- `数模3/outputs_tournament_selected/simulation_results.csv`
- `数模3/outputs_tournament_selected/simulation_results.json`
