# 直接寻优方法说明

## 为什么不能简单宣称全局最优

满足硬约束的分组方案数量极大，若不遍历全部方案，就不能仅凭普通评价排序证明某个方案是全局最优。要严格证明全局最优，通常需要把目标函数转化为整数规划、二次整数规划或约束规划模型，再用分支定界、割平面等精确算法证明最优性。

但本题的综合评价指标包含：

- 小组实力方差；
- 组内两两距离；
- 组内两两竞争悬念；
- 热点对决指数；
- 经济、人口、文旅变异系数；
- TOPSIS 标准化后的相对贴近度。

这些指标含有二次项、分式、平方根和依赖候选集合的归一化过程，直接建立严格线性整数规划较复杂。因此本文采用“可行域内直接启发式寻优”作为可计算方案。

## 方法思想

直接寻优不再先生成大量候选方案池再排序，而是：

1. 先构造一个满足硬约束和同市县级队不重复条件的初始可行方案；
2. 每一步只在县级队之间做交换或三循环置换；
3. 交换前检查新位置是否仍满足：
   - 市级队不与本市县级队同组；
   - 同一市代管县级队不在同一组重复；
   - 每组仍为 4 队；
4. 若新方案的综合目标函数更优，则接受；
5. 若略差，也以一定概率接受，用于跳出局部最优；
6. 多起点重复搜索，保留目标函数最高的若干个非重复方案。

该方法本质上是模拟退火与局部搜索结合的直接优化算法。

## 直接目标函数

对每个可行方案计算与原评价体系一致的指标：

| 指标 | 方向 |
|---|---|
| 同市县级队重复指数 | 越小越好 |
| 成对冲突指数 | 越小越好 |
| 行政来源多样性 | 越大越好 |
| 小组实力方差 | 越小越好 |
| 实力极差 | 越小越好 |
| 竞争悬念 | 越大越好 |
| 热点对决指数 | 越大越好 |
| 经济CV | 越小越好 |
| 人口CV | 越小越好 |
| 文旅CV | 越小越好 |
| 平均组内距离 | 越小越好 |
| 地域覆盖 | 越大越好 |

成本型指标使用：

```text
u_j = 1 / (1 + x_j / s_j)
```

效益型指标使用：

```text
u_j = x_j / s_j
```

或：

```text
u_j = 1 - exp(-x_j / s_j)
```

其中 `s_j` 是指标尺度参数。最后使用 AHP 权重加权：

```text
Score = sum(w_j * u_j)
```

该目标函数可以对单个方案直接打分，因此适合局部搜索；而 TOPSIS 依赖方案集合归一化，更适合作为最终对比评价。

## 已运行结果

运行命令：

```powershell
python direct_optimizer.py --starts 40 --steps 4000 --keep 5 --seed 2026
```

输出目录：

- `outputs_direct/direct_top_schemes.md`
- `outputs_direct/direct_ranking.csv`
- `outputs_direct/direct_best_scheme.csv`
- `outputs_direct/direct_top_schemes.json`

当前直接寻优得到的最优方案为 `D001`，直接目标值为 `0.750790`。相较于原先在 2000 个随机候选方案中排序得到的 `S0390`，`D001` 的实力方差和实力极差显著更低，说明直接优化能更快逼近高质量区域。

## 论文中建议表述

可以写为：

> 由于可行分组方案数量极大，完全枚举所有方案并计算综合评价指标在计算上不可行。为提高搜索效率，本文进一步设计了可行域内直接寻优算法。算法以满足硬约束的方案为初始解，通过县级队交换和三循环置换构造邻域，并在每一步保持硬约束不被破坏。以多指标加权效用函数为优化目标，采用模拟退火准则接受新解，从而在不遍历全部方案的情况下搜索高质量可行解。最后将得到的若干高质量方案再代入 TOPSIS 评价体系进行横向比较。

同时应补一句：

> 该算法属于启发式优化，能够有效获得高质量近优解，但不构成严格全局最优性的数学证明。
