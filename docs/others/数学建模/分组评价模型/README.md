# “浙超”分组评价模型与代码说明

本目录用于问题 1：先生成满足约束的候选分组方案，再按 `建模方案.md` 中的指标计算综合评价分，筛选可行且表现较好的方案。

## 文件

- `group_evaluator.py`：候选方案生成、指标计算、熵权-AHP 组合赋权、TOPSIS 排序、权重扰动稳定性分析。
- `data/teams.csv`：队伍特征表。可由程序生成模板，建议替换为正式查找的数据。
- `outputs/ranking.csv`：候选方案综合排序。
- `outputs/best_scheme.md`：最优方案表和指标值。
- `outputs/best_scheme.csv`：最优方案长表。
- `outputs/candidate_schemes.json`：全部候选方案及指标。
- `outputs/weights.json`：综合评价权重。

## 运行方法

在本目录下运行：

```powershell
python group_evaluator.py --write-template --candidates 300 --seed 2026
```

只重新评价时：

```powershell
python group_evaluator.py --candidates 500 --seed 2026
```

如希望把“同一市代管县级队尽量不同组”作为软约束，而不是强筛选条件：

```powershell
python group_evaluator.py --candidates 500 --allow-repeat-city-counties
```

## 候选方案生成模型

固定编号：

- `G01-G11` 分别固定放入 11 个市级队；
- `G12-G16` 为无市级队小组；
- 每组总人数为 4。

生成时默认满足：

- 每支队伍只进入一个小组；
- 每组恰好 4 支队伍；
- 市级队分配在不同小组；
- 市级队不与其代管县级队同组；
- 同一市代管县级队在任一小组中最多出现 1 支。

最后一条是对题目“尽量不分配在同一小组”的强筛选处理。若要保留软约束差异，可使用 `--allow-repeat-city-counties`。

## 评价指标

程序计算以下指标：

| 指标 | 方向 | 说明 |
|---|---|---|
| `hard_violations` | 必须为 0 | 硬约束违反数 |
| `same_city_repeat_index` | 越小越好 | 同市县级队重复指数 |
| `pair_conflict_index` | 越小越好 | 同市县级队成对冲突指数 |
| `admin_diversity` | 越大越好 | 小组行政来源平均多样性 |
| `sport_variance` | 越小越好 | 16 个小组总实力方差 |
| `sport_range` | 越小越好 | 最强组与最弱组实力差 |
| `competition_suspense` | 越大越好 | 组内队伍实力接近程度 |
| `hot_match_index` | 越大越好 | 热点对决指数 |
| `eco_cv` | 越小越好 | 小组经济指标变异系数 |
| `pop_cv` | 越小越好 | 小组人口指标变异系数 |
| `tour_cv` | 越小越好 | 小组文旅指标变异系数 |
| `avg_inner_distance_km` | 越小越好 | 组内平均地理距离 |
| `geo_cover` | 越大越好 | 小组地域覆盖度 |
| `stability` | 越大越好 | 权重在 ±20% 扰动下进入前 10% 的频率 |

## 综合评价

1. 对成本型指标做反向标准化，对效益型指标做正向标准化。
2. 采用熵权法计算客观权重。
3. 用默认 AHP 主观权重和熵权组合：

```text
w = alpha * w_AHP + (1 - alpha) * w_entropy
```

默认 `alpha=0.5`，可通过 `--alpha` 修改。

4. 用 TOPSIS 计算贴近度，按贴近度降序排序。
5. 对权重做 100 次 ±20% 扰动，计算方案排名稳定性。

## 数据替换建议

`data/teams.csv` 中默认数据用于让模型完整跑通，不应直接作为论文最终实证结论。正式论文建议按以下口径替换：

- 行政区划：使用赛题附录或民政部/浙江省民政厅行政区划资料。
- GDP 与人口：优先使用浙江统计年鉴、各市统计公报、县市统计公报。
- 文旅指标：可使用浙江省文化和旅游厅、各市文旅统计公报、A级景区数量或游客接待量。
- 坐标：可使用高德地图行政区划查询、天地图、国家基础地理信息等公开坐标。
- 足球基础：可使用体育场地数量、校园足球特色学校数量、地方体育事业统计公报；缺失时应明确写为“潜在体育实力代理变量”。

## 可直接写入论文的建模表述

本文首先利用约束规划生成候选方案池，并对每个方案进行硬约束检验。对合格方案，进一步从行政公平性、竞技公平性、观赏性、经济人口文旅均衡性和地理合理性五个维度建立指标体系。由于不同指标量纲和方向不同，先将指标正向化并归一化，再利用 AHP-熵权组合法确定综合权重，最后采用 TOPSIS 方法计算各方案与理想方案的贴近度。为检验推荐方案对权重设置的敏感性，本文在综合权重附近进行随机扰动，统计各方案进入前列的频率，作为方案稳定性指标。
