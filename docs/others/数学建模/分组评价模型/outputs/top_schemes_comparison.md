- 综合得分越高，表示方案越接近多指标理想解。
- 实力方差、实力极差、经济CV、人口CV、文旅CV、平均距离越小越好。
- 竞争悬念、热点指数、地域覆盖、稳定性越大越好。
- 若两个方案综合得分接近，可按论文侧重点选择：重公平则优先实力均衡，重传播则优先热点指数和地域覆盖，重办赛便利则优先平均距离。
