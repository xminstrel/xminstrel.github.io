# 数据资料查找与使用口径

## 已确认可用资料

1. 浙江省统计局、国家统计局浙江调查总队：《2024年浙江省国民经济和社会发展统计公报》  
   可用于省级 GDP、常住人口、体育相关宏观指标等背景说明。公报说明 2024 年全省 GDP 为 90131 亿元，年末常住人口为 6670 万人，并注明最终核实数以《浙江统计年鉴—2025》为准。  
   链接：https://zjzd.stats.gov.cn/zwgk/xxgkml/tjxx/tjgb/202503/t20250311_112495.html

2. 《浙江统计年鉴2025》目录资料  
   目录显示包含“各市、县总户数和总人口数（2024年底数）”等表，可作为县市人口数据的正式来源。若能下载年鉴 Excel/PDF，应优先替换 `data/teams.csv` 中的人口字段。  
   链接：https://www.nianjiandata.com/index.php/books/directory-42539.html

3. 浙江省统计局：《浙江省旅游统计调查制度主要内容（2021-2023年统计年报和2022-2024年定期报表，省文化广电和旅游厅）》  
   可用于说明文旅指标的统计口径。具体县市文旅数据可进一步查各市县文旅局、统计公报或 A 级景区数量。  
   链接：https://tjj.zj.gov.cn/art/2024/3/28/art_1599398_58961659.html

4. 高德地图 API：行政区域查询、地理编码  
   可用于获取市县行政区域中心点经纬度，进而计算组内平均距离。行政区域查询返回 `adcode`、`name`、`center` 等字段；地理编码 API 可把结构化地址转换为经纬度。  
   链接：https://amap.apifox.cn/api-14621407  
   链接：https://amap.apifox.cn/api-14546468

## 数据表字段对应关系

| 程序字段 | 建议资料来源 | 用途 |
|---|---|---|
| `gdp` | 统计年鉴、各市县统计公报 | 经济均衡性、潜在体育实力代理 |
| `population` | 统计年鉴人口表、统计公报 | 人口均衡性、潜在体育实力代理 |
| `tourism` | 文旅统计公报、游客量、旅游收入、A级景区数量 | 文旅均衡性、热点对决指数 |
| `lon`, `lat` | 高德/天地图/地理编码 | 组内平均距离 |
| `football_facility` | 体育场地统计、校园足球特色学校、体育事业公报 | 体育实力代理 |
| `youth_football` | 校园足球、青训、学校体育资料 | 体育实力代理 |
| `sports_investment` | 体育事业经费、场地建设、体育产业数据 | 体育实力代理 |

## 论文中需要说明的限制

当前 `data/teams.csv` 由程序生成的是可运行模板，其中经济、人口、文旅、坐标和足球基础字段是代理数据。若尚未替换为正式资料，论文应写明：

> 由于缺少 64 支参赛队真实历史成绩及完整县域体育数据，本文使用地区经济、人口、文旅和体育基础设施等变量构建“潜在体育实力指数”，该指数仅用于分组方案相对比较，不代表实际球队竞技水平。

最终提交前，建议至少替换 GDP、人口、坐标三类字段；若时间允许，再补充文旅和足球基础字段。
