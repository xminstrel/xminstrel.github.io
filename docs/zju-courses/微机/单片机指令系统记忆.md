
# MCS-51 第三章指令系统速查表

## 一、基础符号和操作数

读懂符号之后，后面所有指令都会容易很多。

|符号|英文含义|中文含义|
|---|---|---|
| `A` / `ACC` |Accumulator|累加器|
| `B` |B Register|B 寄存器|
| `Rn` |Register n|R0～R7 任一工作寄存器|
| `Ri` |Register i|R0 或 R1|
| `DPTR` |Data Pointer|16 位数据指针|
| `PC` |Program Counter|程序计数器|
| `SP` |Stack Pointer|堆栈指针|
| `C` / `CY` |Carry|进位标志位|
| `direct` |Direct Address|直接地址|
| `#data` |Immediate Data|8 位立即数|
| `#data16` |16-bit Immediate Data|16 位立即数|
| `@Ri` |Register Indirect|寄存器间接寻址|
| `bit` |Bit Address|位地址|
| `rel` |Relative Offset|相对偏移量|
| `addr11` |11-bit Address|11 位转移地址|
| `addr16` |16-bit Address|16 位转移地址|

特别记忆： `#` 表示立即数，`@` 表示间接寻址，`C` 表示进位位，`rel` 表示相对偏移量。

## 二、数据传送指令（P10～16）

### 1. 数据移动与交换

|指令|英文含义|功能|示例|
|---|---|---|---|
| `MOV` |Move|传送数据，源不变| `MOV A,#30H` |
| `MOVX` |Move External|访问外部 RAM| `MOVX A,@DPTR` |
| `MOVC` |Move Code|从程序 ROM 读取数据| `MOVC A,@A+DPTR` |
| `XCH` |Exchange|交换两个字节| `XCH A,R0` |
| `XCHD` |Exchange Digits|交换低 4 位，高 4 位不变| `XCHD A,@R0` |
| `SWAP` |Swap|交换 A 的高低 4 位| `SWAP A` |
| `PUSH` |Push|压栈，SP 先加 1| `PUSH 30H` |
| `POP` |Pop|出栈，SP 后减 1| `POP 30H` |

### 2. MOV 的常见用法

|指令格式|功能|
|---|---|
| `MOV A,#data` |立即数送 A|
| `MOV A,direct` |内部 RAM 或 SFR 的数据送 A|
| `MOV A,Rn` |工作寄存器内容送 A|
| `MOV A,@Ri` |间接寻址读取内部 RAM|
| `MOV Rn,A` |A 的内容送 Rn|
| `MOV direct,A` |A 的内容写入直接地址|
| `MOV direct,#data` |立即数写入直接地址|
| `MOV DPTR,#data16` |设置 16 位数据指针|

记忆方法：

`MOV` 中的 `MOV` 是 Move，`MOVC` 多了 Code，`MOVX` 多了 External。

因此可以记为：

“MOV 搬内部，MOVC 读程序，MOVX 访外部。”

注意，8051 不支持任意寄存器之间直接传送，例如 `MOV R6,R7` 不合法，需要通过 A 中转。

## 三、算术运算指令（P17～21）

|指令|英文含义|中文功能|用法示例|
|---|---|---|---|
| `ADD` |Add|普通加法| `ADD A,#20H` |
| `ADDC` |Add with Carry|带进位加法| `ADDC A,R0` |
| `SUBB` |Subtract with Borrow|带借位减法| `SUBB A,#10H` |
| `INC` |Increment|加 1| `INC R0` |
| `DEC` |Decrement|减 1| `DEC R1` |
| `MUL` |Multiply|无符号乘法| `MUL AB` |
| `DIV` |Divide|无符号除法| `DIV AB` |
| `DA` |Decimal Adjust|BCD 加法后的十进制调整| `DA A` |

### 三个重要区别

|指令|数学表达式|特别注意|
|---|---|---|
| `ADD A,src` |A = A + src|不加原 CY|
| `ADDC A,src` |A = A + src + CY|加原 CY|
| `SUBB A,src` |A = A − src − CY|减原 CY|

其中 `src` 表示源操作数。

乘法、除法的结果存放方式：

|指令|A 中的结果|B 中的结果|
|---|---|---|
| `MUL AB` |乘积低 8 位|乘积高 8 位|
| `DIV AB` |商|余数|

英文记忆规律：

`INC` = Increment，意思是增加。

`DEC` = Decrement，意思是减少。

`SUBB` 中的 B = Borrow（借位）。

`ADDC` 中的 C = Carry（进位）。

记住：“INC 加一，DEC 减一；ADD 不带进，ADDC 带进位；SUBB 要减借位。”

## 四、逻辑运算与移位指令（P22～26）

### 1. 逻辑运算

|指令|英文含义|功能|示例|
|---|---|---|---|
| `ANL` |Logical AND|按位与| `ANL A,#0FH` |
| `ORL` |Logical OR|按位或| `ORL A,#80H` |
| `XRL` |Logical Exclusive OR|按位异或| `XRL A,#0FFH` |
| `CLR` |Clear|清零| `CLR A` |
| `CPL` |Complement|按位取反| `CPL A` |

其中 ANL、ORL、XRL 可以这样理解：AND、OR、XOR 是逻辑运算名称，助记符中的 `L` 表示 Logical（逻辑）。

### 2. 循环移位

|指令|英文含义|功能|是否经过 CY|
|---|---|---|---|
| `RL` |Rotate Left|A 循环左移|否|
| `RLC` |Rotate Left through Carry|A 经 CY 循环左移|是|
| `RR` |Rotate Right|A 循环右移|否|
| `RRC` |Rotate Right through Carry|A 经 CY 循环右移|是|

记忆口诀：

“R 是 Rotate，L 是 Left，R 是 Right，C 是 Carry。”

也就是说：

`RL` 是向左循环，`RR` 是向右循环；末尾加 `C`，就是需要经过进位位 CY。

### 3. 逻辑运算速记

|运算|规则|常见用途|
|---|---|---|
| `ANL` |全 1 得 1|屏蔽、清除某些位|
| `ORL` |有 1 得 1|将某些位置 1|
| `XRL` |不同得 1|翻转某些位|
| `CLR` |清零|把 A 或指定位变成 0|
| `CPL` |取反|把 0 变 1、1 变 0|

其中 `XRL` 最值得记住的是：一个数与同一个掩码异或两次，会恢复原值。

## 五、控制转移指令（P27～29）

这部分是后面第四章分支程序、循环程序设计的核心。

### 1. 无条件转移指令

|指令|英文含义|功能|示例|
|---|---|---|---|
| `LJMP` |Long Jump|长跳转，64 KB 程序地址范围| `LJMP MAIN` |
| `AJMP` |Absolute Jump|绝对跳转，限定在同一 2 KB 页面| `AJMP NEXT` |
| `SJMP` |Short Jump|短相对跳转，偏移 -128～+127| `SJMP LOOP` |
| `JMP` |Jump|跳转；课件为计算地址跳转| `JMP @A+DPTR` |

这里最主要的区别是前面的字母：

|前缀|英文单词|记忆|
|---|---|---|
| `L` |Long|长距离|
| `A` |Absolute|绝对地址|
| `S` |Short|短距离|

注意 `AJMP` 的范围并不是任意前后 2 KB，而是目标要处在跳转指令之后的 PC 所在的同一个 2 KB 页面。

### 2. 条件转移指令

|指令|英文含义|跳转条件|示例|
|---|---|---|---|
| `JZ` |Jump if Zero|A = 0| `JZ NEXT` |
| `JNZ` |Jump if Not Zero|A ≠ 0| `JNZ LOOP` |
| `JC` |Jump if Carry|CY = 1| `JC NEXT` |
| `JNC` |Jump if No Carry|CY = 0| `JNC NEXT` |
| `JB` |Jump if Bit Set|指定位为 1| `JB P1.0,NEXT` |
| `JNB` |Jump if Not Bit Set|指定位为 0| `JNB P1.0,NEXT` |
| `JBC` |Jump if Bit Set and Clear|位为 1 时，清零该位并跳转| `JBC P1.0,NEXT` |
| `CJNE` |Compare and Jump if Not Equal|比较不相等则跳转| `CJNE A,#20H,NEXT` |
| `DJNZ` |Decrement and Jump if Not Zero|减 1 后不为 0 则跳转| `DJNZ R0,LOOP` |

这里有一套很重要的英文规律：

|字母或组合|英文|中文|
|---|---|---|
| `J` |Jump|跳转|
| `Z` |Zero|零|
| `N` |Not / No|不、非、无|
| `C` |Carry|进位|
| `B` |Bit|位|
| `NE` |Not Equal|不相等|
| `DJ` |Decrement + Jump|减 1 并跳转|
| `CJ` |Compare + Jump|比较并跳转|

因此遇到 `JNZ`，就可以直接拆成：

J（Jump）+ N（Not）+ Z（Zero） = 非零跳转。

遇到 `DJNZ`：

D（Decrement）+ J（Jump）+ NZ（Not Zero） = 减 1 后非零跳转。

特别注意，`CJNE` 除了决定是否跳转，还会改变 CY：无符号比较时，第一操作数小于第二操作数，CY 置 1，否则清 0。

### 3. 子程序和其他控制指令

|指令|英文含义|功能|示例|
|---|---|---|---|
| `ACALL` |Absolute Call|绝对子程序调用| `ACALL DELAY` |
| `LCALL` |Long Call|长子程序调用| `LCALL DELAY` |
| `RET` |Return|普通子程序返回| `RET` |
| `RETI` |Return from Interrupt|中断服务程序返回| `RETI` |
| `NOP` |No Operation|空操作| `NOP` |

记忆：CALL 是调用，RET 是返回，RETI 多了 Interrupt（中断）。

子程序调用时会把返回地址压入堆栈，返回时再恢复。因此普通 `LCALL`、`ACALL` 会使 SP 增加 2，`RET` 会使 SP 减少 2。

## 六、位操作指令（P30）

位操作的核心是直接控制某一个二进制位。

|指令|英文含义|功能|示例|
|---|---|---|---|
| `MOV C,bit` |Move|将某一位送到 CY| `MOV C,P1.0` |
| `MOV bit,C` |Move|将 CY 送到某一位| `MOV P1.0,C` |
| `CLR C` |Clear Carry|CY 清零| `CLR C` |
| `CLR bit` |Clear Bit|指定位清零| `CLR P1.0` |
| `SETB C` |Set Bit|CY 置 1| `SETB C` |
| `SETB bit` |Set Bit|指定位置 1| `SETB P1.0` |
| `CPL C` |Complement Carry|CY 取反| `CPL C` |
| `CPL bit` |Complement Bit|指定位取反| `CPL P1.0` |
| `ANL C,bit` |Logical AND|CY 与某一位相与| `ANL C,P1.0` |
| `ORL C,bit` |Logical OR|CY 与某一位相或| `ORL C,P1.0` |

注意，`ANL C,/bit` 和 `ORL C,/bit` 也合法，`/bit` 表示使用该位的逻辑反值参与运算，不会修改原来的位。

最方便的记忆方式：

CLR 清零、SETB 置一、CPL 取反。

## 七、伪指令（P32～35）

伪指令（Assembler Directives）不由 CPU 执行，而是用于指导汇编程序组织源代码和数据。

|伪指令|英文含义|功能|示例|
|---|---|---|---|
| `ORG` |Origin|设置后续代码或数据的起始地址| `ORG 0000H` |
| `END` |End|表示汇编源程序结束| `END` |
| `EQU` |Equate|为一个符号定义固定值| `COUNT EQU 20H` |
| `DB` |Define Byte|定义 8 位数据| `DB 12H,34H` |
| `DW` |Define Word|定义 16 位数据| `DW 1234H` |
| `BIT` |Bit|定义位地址符号| `LED BIT P1.0` |
| `DATA` |Data|定义字节地址符号| `X DATA 30H` |

这些伪指令的英文含义也可以在汇编器相关文档中得到对应说明。

gpmanesar.ac.in+1

这里特别需要区分 `ORG`、`DB` 和 `EQU`：

|指令|是否在指定位置生成数据|理解|
|---|---|---|
| `ORG 2000H` |否|指定后续内容从哪里放|
| `DB 12H,34H` |是|写入两个字节常数|
| `X EQU 30H` |否|用 X 代表 30H|

例如：

```
ORG 2000H
TAB: DB 12H,34H,56H

END
```

这样 ROM 的 `2000H`、`2001H`、`2002H` 地址会依次存放 `12H`、`34H`、`56H`。

# 八、七种寻址方式与英文对应表

虽然寻址方式不是单独的指令，但它决定了如何理解操作数，建议和前面的指令放在一起记忆。

|寻址方式|英文名称|示例|含义|
|---|---|---|---|
|立即寻址|Immediate Addressing| `MOV A,#20H` |数据直接给出|
|直接寻址|Direct Addressing| `MOV A,20H` |直接给出数据地址|
|寄存器寻址|Register Addressing| `MOV A,R0` |直接读取寄存器|
|寄存器间接寻址|Register Indirect Addressing| `MOV A,@R0` |地址保存在寄存器中|
|变址寻址|Indexed Addressing| `MOVC A,@A+DPTR` |基址加偏移量|
|相对寻址|Relative Addressing| `SJMP LOOP` |相对当前执行位置跳转|
|位寻址|Bit Addressing| `SETB P1.0` |直接操作某一位|

## 十、最容易误用的指令组合

|容易写错的形式|问题|正确写法|
|---|---|---|
| `MOV R6,R7` |不支持这样直接传送|先 `MOV A,R7`，再 `MOV R6,A` |
| `MOV A,@R2` |普通间接寻址不能使用 R2|使用 `@R0` 或 `@R1` |
| `MOVC A,@DPTR` |MOVC 需要 A 参与变址| `MOVC A,@A+DPTR` |
| `SUB A,#10H` |8051 没有 SUB 指令| `SUBB A,#10H` |
| `DEC DPTR` |不支持 DPTR 直接减 1|需要其他指令组合|
| `MUL A,B` |乘法指令不这样写| `MUL AB` |
| `DIV A,B` |除法指令不这样写| `DIV AB` |
| `CLR R0` |CLR 不支持直接清零 R0| `MOV R0,#00H` |
