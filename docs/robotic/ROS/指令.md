
# 1. Linux 路径与符号速查表

|写法|含义|例子|说明|
|---|---|---|---|
| `~` |当前用户的家目录| `cd ~` |你这里就是 `/home/xmins` |
| `/home/xmins` |你的家目录完整写法| `cd /home/xmins` |和 `cd ~` 等价|
| `/` |根目录| `cd /` |Linux 最顶层目录|
| `.` |当前目录| `cd .` |一般很少单独用|
| `..` |上一级目录| `cd ..` |回到上一层|
| `../..` |上两级目录| `cd ../..` |连退两层|
| `/mnt/c` |Windows 的 C 盘| `cd /mnt/c` |WSL 里访问 Windows 文件|
| `/mnt/c/Users/XMins` |Windows 用户目录| `cd /mnt/c/Users/XMins` |你 Windows 里的用户文件夹|
| `~/ros2_ws` |家目录下的 `ros2_ws` | `cd ~/ros2_ws` |实际是 `/home/xmins/ros2_ws` |
|绝对路径|从根目录开始写的路径| `/home/xmins/test` |不管你现在在哪，都能找到|
|相对路径|相对当前目录写的路径| `cd test` |只有当前目录下有 `test` 才行|

# 2. 你现在最常用的 Linux 命令表

|命令|作用|例子|你可以怎么理解|
|---|---|---|---|
| `pwd` |查看当前目录| `pwd` |我现在在哪|
| `cd` |切换目录| `cd ~` |回家目录|
| `ls` |查看当前目录内容| `ls` |看这里有什么文件|
| `ls -l` |详细查看文件| `ls -l` |看文件详情|
| `mkdir` |新建文件夹| `mkdir test` |创建一个文件夹|
| `mkdir -p` |递归创建文件夹| `mkdir -p ~/ros2_ws/src` |一次建好多层|
| `rm` |删除文件| `rm a.txt` |删除文件|
| `rm -r` |删除文件夹| `rm -r test` |删除整个文件夹|
| `cp` |复制文件| `cp a.txt b.txt` |复制一份|
| `mv` |移动或重命名| `mv a.txt b.txt` |改名或移动|
| `clear` |清屏| `clear` |清空终端显示|
| `sudo` |用管理员权限执行| `sudo apt update` |提权执行|
| `apt update` |更新软件源列表| `sudo apt update` |刷新可安装软件信息|
| `apt upgrade` |升级已安装软件| `sudo apt upgrade -y` |更新系统软件|
| `apt install` |安装软件| `sudo apt install curl -y` |安装某个软件|
| `source` |让配置立刻生效| `source ~/.bashrc` |重新加载配置|
| `echo` |输出一行文字| `echo hello` |打印内容|
| `cat` |查看文件内容| `cat /etc/os-release` |查看文本文件|

# 3. ROS 2 常用命令表

|命令|作用|例子|说明|
|---|---|---|---|
| `ros2 --help` |查看 ROS 2 帮助| `ros2 --help` |不会时先看它|
| `ros2 run` |运行某个 ROS 2 程序| `ros2 run demo_nodes_cpp talker` |运行包里的节点|
| `ros2 node list` |查看当前节点| `ros2 node list` |看现在有哪些节点在运行|
| `ros2 topic list` |查看当前话题| `ros2 topic list` |看有哪些 topic|
| `ros2 topic list -t` |查看话题和类型| `ros2 topic list -t` |比 `list` 更详细|
| `ros2 topic echo` |查看某个话题内容| `ros2 topic echo /chatter` |直接看消息内容|
| `ros2 topic info` |查看话题信息| `ros2 topic info /chatter` |看发布者和订阅者|
| `ros2 service list` |查看服务| `ros2 service list` |后面学 service 会用|
| `ros2 action list` |查看 action| `ros2 action list` |后面学 action 会用|
| `ros2 pkg list` |查看已安装包| `ros2 pkg list` |看有哪些 ROS 包|
| `rviz2` |打开 RViz 2| `rviz2` |可视化工具|

# 5. 你现在最常见的完整操作流程

|场景|命令|
|---|---|
|打开 Ubuntu 后先加载环境| `source ~/.bashrc` |
|运行发布节点| `ros2 run demo_nodes_cpp talker` |
|运行订阅节点| `ros2 run demo_nodes_py listener` |
|查看节点是否存在| `ros2 node list` |
|查看话题是否存在| `ros2 topic list` |
|查看 `/chatter` 消息| `ros2 topic echo /chatter` |

# 6. 你最容易混淆的几个点

|看到的东西|是什么|例子|
|---|---|---|
| `sudo apt ...` |Ubuntu/Linux 命令| `sudo apt update` |
| `ros2 ...` |ROS 2 命令| `ros2 topic list` |
| `~` |家目录简写| `/home/xmins` |
| `/mnt/c/...` |Windows 磁盘路径| `/mnt/c/Users/XMins` |
| `source ~/.bashrc` |重新加载终端配置|不是安装命令|
