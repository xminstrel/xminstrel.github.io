**具身智能与机器人学习长期学习路线图**

从软体机器人形态感知出发，走向 Robot Learning / Diffusion Policy / World Model / VLA

适用周期：2026–2029（可滚动更新）

近期执行版本：未来 8 周 + 12 个月

# 一、总体定位与长期目标

你当前最有价值的积累，不是某一个传感器结构本身，而是已经开始接触“机械结构—传感器—状态估计—控制—ROS—深度学习”这一整条机器人链路。未来更建议把研究定位逐步提升为“机器人感知与学习（Robot Perception & Learning）”，并把软体机器人本体感知作为第一个可持续研究入口。

长期目标不是“会运行几个大模型仓库”，而是形成四层能力：① 能把真实机器人问题抽象成机器学习问题；② 能独立设计、训练、诊断模型；③ 能在仿真和真实机器人中闭环验证策略；④ 能阅读最新论文并做出自己的算法改进。

## 建议形成的个人技术标签

- 机器人本体感知（proprioception）与多模态感知

- 模仿学习 / Robot Learning

- Diffusion Policy 与生成式策略模型

- World Model / Model-based Robot Learning

- VLA（Vision-Language-Action）与机器人基础模型

- ROS2 + MuJoCo / Isaac Lab + 真实硬件验证

# 二、学习原则：避免“学很多但不会做”

- 每一个理论模块都必须对应一个可运行项目。没有代码和实验的“学完”不算完成。

- 先做 baseline，再做复杂模型。任何研究问题先跑通线性回归 / MLP / LSTM / Behavior Cloning，再谈 Diffusion、VLA。

- 优先官方课程、经典教材、顶会/顶刊论文和作者开源代码；减少碎片化二手教程。

- 机器人学习要保持“算法 + 实体系统”双线：既看 loss 和 architecture，也关注传感器噪声、时延、采样频率、控制周期和安全。

- 论文阅读采用三遍法：第一遍抓问题与结论，第二遍抓方法框图和训练目标，第三遍再看公式与实现。

- 每 4–8 周必须产出一个可以展示的 GitHub 项目，而不是只积累笔记。

# 三、阶段 A：深度学习与 PyTorch 基础（0–2 个月）

目标：能不依赖现成训练框架，从 Dataset/DataLoader 开始独立写出一个监督学习项目，并能定位过拟合、欠拟合、数据泄漏和训练不收敛问题。

## 必须掌握

- NumPy 与张量维度；矩阵乘法与广播

- PyTorch Tensor、autograd、nn.Module、Dataset/DataLoader

- 训练/验证/测试集划分

- MSE、MAE、Cross-Entropy；Adam/AdamW；学习率

- BatchNorm、Dropout、权重衰减

- MLP、CNN 基础、RNN/LSTM/GRU 基础

- Transformer 的 Attention、位置编码、Encoder

- 实验记录：seed、配置、checkpoint、指标、曲线

## 高认可度资源

**PyTorch 官方 Learn the Basics：**官方、更新稳定；覆盖 Tensor、DataLoader、模型、Autograd、Optimization [<u>访问资源</u>](https://docs.pytorch.org/tutorials/beginner/basics/intro.html)

**Stanford CS231n：**Stanford 经典深度学习/视觉课程；2025 作业包含 Transformer、Diffusion、CLIP、DINO [<u>访问资源</u>](https://cs231n.stanford.edu/2025/)

**Dive into Deep Learning (D2L)：**开源交互式教材；适合作为数学 + PyTorch 查漏补缺 [<u>访问资源</u>](https://d2l.ai/)

## 阶段项目

1.  波纹管形态预测 baseline：多通道电容 → 角度 / 曲率，先完成 Linear Regression、MLP。

2.  加入时间窗口：C\[t−N:t\] → θ(t)，比较 MLP、GRU/LSTM。

3.  形成统一训练模板：config、dataset、model、train、evaluate、plot。以后所有项目复用。

# 四、阶段 B：机器人基础、控制与仿真（并行进行，0–4 个月）

模型算法不能脱离机器人系统。你不需要先成为传统控制专家，但必须知道状态、动作、观测、动力学、反馈、轨迹、MDP 分别是什么。

## 建议掌握的最低机器人知识

- 刚体运动学：坐标系、旋转矩阵、齐次变换

- 机械臂正/逆运动学的基本概念

- 状态空间模型、反馈控制、PID/LQR 的直觉

- 轨迹与控制频率；位置/速度/力控制

- MDP：state、observation、action、reward、transition

- POMDP 与“为什么历史观测有价值”

- ROS2：topic / service / action / tf2 / rosbag

## 高认可度资源

**MIT Underactuated Robotics — Russ Tedrake：**机器人动力学、控制、轨迹优化、状态估计、模仿学习；在线讲义免费且完整 [<u>访问资源</u>](https://underactuated.mit.edu/)

**MuJoCo — Google DeepMind：**机器人学习领域常用物理引擎；官方 Python 教程可直接在 Colab 运行 [<u>访问资源</u>](https://github.com/google-deepmind/mujoco)

**NVIDIA Isaac Lab：**面向 robot learning 的 GPU 并行仿真框架，支持 imitation learning 与 reinforcement learning [<u>访问资源</u>](https://developer.nvidia.com/isaac/lab)

近期优先级：先 MuJoCo，后 Isaac Lab。MuJoCo 更轻量，适合 Mac 和算法学习；Isaac Lab 更适合后期有 NVIDIA GPU 时做大规模并行训练。

# 五、阶段 C：Diffusion 与生成式建模（2–5 个月）

目标：理解 diffusion 不是“画图模型”，而是一类从噪声逐步采样复杂分布的方法。对机器人最重要的是 conditional diffusion 和 action sequence generation。

## 学习顺序

4.  概率基础：高斯分布、条件概率、期望/方差、KL divergence（理解即可，不追求纯数学推导）

5.  DDPM forward process 与 reverse process

6.  noise schedule、time embedding、ε-prediction

7.  1D / time-series diffusion

8.  Conditional diffusion：把传感器 / observation 作为条件

9.  Diffusion Policy：把 action chunk 作为生成对象

## 核心论文与项目

**Denoising Diffusion Probabilistic Models (Ho et al., 2020)：**DDPM 基础论文 [<u>访问资源</u>](https://arxiv.org/abs/2006.11239)

**Diffusion Policy: Visuomotor Policy Learning via Action Diffusion (RSS 2023 / IJRR)：**生成式机器人策略的代表作；将 conditional diffusion 用于动作序列 [<u>访问资源</u>](https://diffusion-policy.cs.columbia.edu/)

**real-stanford/diffusion_policy：**作者官方代码，提供 state-based 与 vision-based Colab [<u>访问资源</u>](https://github.com/real-stanford/diffusion_policy)

## 你自己的研究连接

第一步：p(shape \| capacitance)。将多通道电容作为 condition，让 diffusion 生成曲率/分段角度/中心线分布。

第二步：p(action \| observation)。将视觉 + 电容/本体状态作为 observation，让 diffusion 生成未来一段动作。此时就从“传感器算法”真正进入 Robot Learning。

# 六、阶段 D：模仿学习与 Robot Learning（3–8 个月）

这是整个路线的核心阶段。目标是理解：机器人策略本质上是在学习 π(a\|o) 或 π(a\_{t:t+H}\|o\_{≤t})，而不是单纯做分类。

## 学习顺序

- Behavior Cloning（BC）：监督学习式策略

- Distribution Shift 与 DAgger 的思想

- Action Chunking：一次预测一段动作

- ACT（Action Chunking with Transformers）

- Diffusion Policy

- Offline RL 基础概念

- 视觉编码器 + proprioception 融合

## 最推荐的资源组合

**UC Berkeley CS 185/285 Deep Reinforcement Learning：**Sergey Levine 课程；当前页面为 2026 offering，覆盖 imitation learning、RL、model-based RL、offline RL [<u>访问资源</u>](https://rail.eecs.berkeley.edu/deeprlcourse/)

**Stanford CS224R Deep Reinforcement Learning：**聚焦高维观测、机器人、demonstrations、model-based/model-free、offline RL [<u>访问资源</u>](https://cs224r.stanford.edu/spring_2025/)

**LeRobot — Hugging Face：**非常适合作为你的第一个现代 robot learning 工程框架：Teleoperate → Record → Train → Deploy；同时包含 ACT、VLA 等策略 [<u>访问资源</u>](https://huggingface.co/docs/lerobot/main/index)

**ACT in LeRobot：**LeRobot 官方把 ACT 推荐为初学者第一种策略，轻量、训练快、数据需求相对低 [<u>访问资源</u>](https://huggingface.co/docs/lerobot/act)

**Diffusion Policy：**你的生成式策略主线 [<u>访问资源</u>](https://diffusion-policy.cs.columbia.edu/)

## 阶段成果要求

10. 在 Push-T 或类似 benchmark 上训练 Behavior Cloning。

11. 复现 ACT 或 LeRobot 中的一个 imitation learning policy。

12. 复现 Diffusion Policy 的 state-based Push-T，再做 vision-based。

13. 写一份 5–10 页实验报告：数据、输入输出、architecture、loss、evaluation、failure cases。

# 七、阶段 E：World Model 与 VLA（6–18 个月）

World Model 和 VLA 是中长期方向，不宜作为第一个入口。你应该在已经完成一个 robot policy 项目后再进入，否则很容易只停留在“大模型微调脚本”。

## World Model 路线

核心问题：学习环境动力学 p(s\_{t+1}\|s_t,a_t)，并用“想象出来的未来”进行规划或策略优化。

- Model-based RL 基础

- latent dynamics / recurrent state-space model

- Dreamer 系列

- 视频/视觉世界模型的基本思想

- 把自己的软体机器人做成：当前形态 + 动作 → 下一时刻形态

**代表项目 DreamerV3：**通过 world model 学习未来 latent state，并在 imagined trajectories 上训练策略。[<u>GitHub</u>](https://github.com/danijar/dreamerv3)

## VLA / Generalist Robot Policy 路线

**Octo：**开源 generalist robot policy；Transformer-based diffusion policy，预训练于约 80 万机器人轨迹 [<u>访问资源</u>](https://github.com/octo-models/octo)

**OpenVLA：**开源 Vision-Language-Action 模型；支持 LoRA / full fine-tuning 与 LIBERO 评测 [<u>访问资源</u>](https://github.com/openvla/openvla)

**Open X-Embodiment：**Google DeepMind 主导的统一机器人数据集合与 RT-X 生态 [<u>访问资源</u>](https://github.com/google-deepmind/open_x_embodiment)

**π₀ (Physical Intelligence)：**代表性的通用机器人 foundation policy；理解趋势即可，先不作为近期复现目标 [<u>访问资源</u>](https://www.pi.website/blog/pi0)

建议顺序：LeRobot/ACT → Diffusion Policy → Octo → OpenVLA → 再追踪更大的 VLA / foundation policy。

# 十三、建议构建的个人项目作品集

比“学了哪些课程”更重要的是你最终能展示哪些项目。建议 GitHub 首页最终形成以下项目阶梯：

- 01 — capacitance-shape-baselines：MLP / LSTM / GRU 预测波纹管形态。

- 02 — 1d-diffusion-from-scratch：从零实现一维 DDPM。

- 03 — conditional-shape-diffusion：电容条件扩散生成曲率/形态。

- 04 — mujoco-robot-learning-playground：MuJoCo 控制与数据采集。

- 05 — imitation-learning-baselines：Behavior Cloning / ACT。

- 06 — diffusion-policy-reproduction：Push-T 或 robomimic benchmark。

- 07 — multimodal-robot-policy：视觉 + 本体感知融合。

- 08 — embodied-world-model：状态/动作 → 下一时刻状态。

- 09 — vla-finetuning-notes：Octo/OpenVLA/LeRobot 复现和微调。

## 项目 README 至少包含

- Problem：任务是什么，输入输出是什么

- Method：baseline 和模型结构

- Dataset：数据规模、采样、划分方法

- Training：loss、optimizer、超参数

- Metrics：不仅给最好结果，还要给 baseline

- Failure cases：失败案例和原因分析

- Reproduce：一条命令可以训练/评估

- Demo：GIF / 视频 / 曲线

|------------------|--------------------------------------------------------------------------------------------|
| PyTorch          | 一个 batch 如何从 DataLoader 进入模型？为什么要 zero_grad？train/eval 模式差在哪？         |
| 监督学习         | 为什么训练误差很低但测试误差很高？怎样发现数据泄漏？                                       |
| 时序模型         | 为什么单帧传感器输入可能不够？window length 对信息和时延有什么影响？                       |
| Diffusion        | x0、xt、ε 分别是什么？训练阶段与 sampling 阶段的差别是什么？                               |
| Robot Learning   | observation、state、action、policy、trajectory 各是什么？为什么 BC 会 distribution shift？ |
| Diffusion Policy | 为什么生成 action chunk，而不是单个 action？condition 是怎样进入网络的？                   |
| World Model      | 为什么学 transition model？model error 为什么会影响规划？                                  |
| VLA              | 视觉、语言、动作如何统一进模型？动作是连续值还是 token？微调时数据格式如何处理？           |
