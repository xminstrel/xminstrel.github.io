| 类型                             | 典型例子               | 主要控制问题           |
| ------------------------------ | ------------------ | ---------------- |
| 固定式机械臂（Fixed-base Manipulator） | 工业六轴机械臂、协作机械臂      | 末端精确运动、轨迹跟踪、力控制  |
| 移动机器人（Mobile Robot）            | 轮式小车、自动驾驶车、无人机、AGV | 定位、路径规划、避障、轨迹跟踪  |
| 腿足机器人（Legged Robot）            | 四足机器人、人形机器人        | 平衡、步态、接触力控制、全身协调 |
| 移动机械臂（Mobile Manipulator）      | 轮式底盘 + 机械臂         | 底盘移动 + 机械臂操作协同   |
| 软体机器人（Soft Robot）              | 软体夹爪、仿生手           | 柔顺控制、材料变形、非线性建模  |



## 控制方法表格

| 方法    | 解释       | 应用         |
| ----- | -------- | ---------- |
| PID控制 | 偏了就修正    | 电机、关节、巡线   |
| 前馈+反馈 | 先预测，再纠偏  | 机械臂轨迹      |
| MPC   | 预测未来再优化  | 自动驾驶、腿足机器人 |
| 阻抗控制  | 控制接触软硬   | 装配、抓取      |
| 自适应控制 | 环境变化时调参数 | 负载变化、复杂地形  |
| 鲁棒控制  | 有扰动也稳定   | 不确定系统      |
