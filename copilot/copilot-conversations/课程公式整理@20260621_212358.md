## 一、绪论：三种基本传热方式

### 1. 热传导（傅里叶定律）
**稳态一维导热：**

$$\Phi = -\lambda A \frac{dt}{dx} = \lambda A \frac{\Delta t}{\delta}$$

$$q = \frac{\Phi}{A} = \lambda \frac{\Delta t}{\delta}$$

**导热热阻：**  
$$R = \frac{\delta}{\lambda A} \quad \text{或} \quad r = \frac{\delta}{\lambda}$$

### 2. 热对流（牛顿冷却公式）
$$\Phi = hA(t_w - t_\infty)$$

$$q = h(t_w - t_\infty)$$

**对流热阻：**  
$$R_h = \frac{1}{hA} \quad \text{或} \quad r_h = \frac{1}{h}$$

### 3. 热辐射（斯蒂芬-玻尔兹曼定律）
黑体辐射力：
$$E_b = \sigma T^4$$
其中 $\sigma = 5.67 \times 10^{-8} \, \text{W/(m}^2\cdot\text{K}^4)$

## 二、稳态导热

### 1. 导热微分方程（直角坐标，常物性）
$$\frac{\partial t}{\partial \tau} = a \nabla^2 t + \frac{\dot q_v}{\rho c}$$
热扩散率：$a = \frac{\lambda}{\rho c}$

稳态无内热源：$\nabla^2 t = 0$

一维稳态无内热源：$\frac{d^2 t}{dx^2} = 0$

### 2. 三类边界条件
- 第一类：$t_w = f(\tau)$ （已知壁温）
- 第二类：$-\lambda \frac{\partial t}{\partial n} = q_w$ （已知热流密度）
- 第三类：$-\lambda \frac{\partial t}{\partial n} = h(t_w - t_f)$ （对流换热）

### 3. 一维稳态导热温度分布与热流量

| 几何类型 | 温度分布 | 热流量 $\Phi$ | 热阻 $R$ |
|---------|---------|-------------|---------|
| 单层平壁 | $t = t_1 - \frac{t_1 - t_2}{\delta}x$ | $\frac{\lambda A (t_1 - t_2)}{\delta}$ | $\frac{\delta}{\lambda A}$ |
| 多层平壁（n层） | — | $\frac{t_1 - t_{n+1}}{\sum \frac{\delta_i}{\lambda_i A}}$ | $\sum \frac{\delta_i}{\lambda_i A}$ |
| 圆筒壁（长l） | $t = t_1 + \frac{t_2 - t_1}{\ln(r_2/r_1)}\ln\frac{r}{r_1}$ | $\frac{2\pi l \lambda (t_1 - t_2)}{\ln(r_2/r_1)}$ | $\frac{\ln(r_2/r_1)}{2\pi l \lambda}$ |
| 球壁 | $t = t_1 + (t_2 - t_1)\frac{1/r_1 - 1/r}{1/r_1 - 1/r_2}$ | $\frac{4\pi\lambda (t_1 - t_2)}{1/r_1 - 1/r_2}$ | $\frac{1/r_1 - 1/r_2}{4\pi\lambda}$ |

### 4. 有均匀内热源的一维稳态导热
**平壁**（中心面 $x=0$，壁面 $x=\delta$）：
$$t = t_w + \frac{\dot q_v}{2\lambda}(\delta^2 - x^2)$$
中心最高温度：$t_{\max} = t_w + \frac{\dot q_v \delta^2}{2\lambda}$

**圆柱体**（中心 $r=0$，壁面 $r=R$）：
$$t = t_w + \frac{\dot q_v}{4\lambda}(R^2 - r^2)$$
中心最高温度：$t_{\max} = t_w + \frac{\dot q_v R^2}{4\lambda}$

## 三、对流换热原理

### 1. 主要无量纲数
- **雷诺数**：$Re = \frac{uL}{\nu}$ （判断流态，层流/湍流）
- **普朗特数**：$Pr = \frac{\nu}{a}$ （流体物性参数）
- **努塞尔数**：$Nu = \frac{hL}{\lambda}$ （反映对流换热强度）
- **格拉晓夫数**：$Gr = \frac{g\beta \theta_w L^3}{\nu^2}$ （自然对流）

### 2. 边界层厚度
- 速度边界层：$\delta = \frac{4.64x}{\sqrt{Re_x}}$
- 热边界层：$\delta_t = \frac{1}{1.026 \sqrt[3]{Re_x}}$

## 四、对流换热计算

### 1. 管内强制对流（湍流）
**流动换热平衡方程：**
$$\frac{\pi d^2}{4} \rho c_p u_m (t_f' - t_f'') = h \pi d l \Delta t_m$$

**管内湍流准则式（$Re > 10^4$）：**
$$Nu = 0.023 \, Re^{0.8} Pr^n$$
加热时 $n=0.4$，冷却时 $n=0.3$

### 2. 外掠平板
- 层流（$Re < 5\times10^5$）：$Nu_x = 0.332 \, Re_x^{1/2} Pr^{1/3}$
- 湍流：$Nu_x = 0.0296 \, Re_x^{4/5} Pr^{1/3}$

### 3. 横向掠过圆柱 / 管束
（具体经验公式按教材或考卷给定常数，开卷考试时注意查表）

### 4. 自然对流
**大空间自然对流：**
$$Nu = c(Gr \cdot Pr)^n$$
常数 $c, n$ 由 Gr·Pr 范围和几何形状决定（考卷会提供或可查表）

**转折判据**：$Gr > 10^9$ 时边界层从层流变为湍流

## 五、热辐射基础

### 1. 黑体辐射基本定律
- **普朗克定律**：$E_{b\lambda} = \frac{C_1 \lambda^{-5}}{\exp(C_2/\lambda T) - 1}$
- **维恩位移定律**：$\lambda_{\max} T = 2.898\times10^{-3} \, \text{m·K}$
- **斯蒂芬-玻尔兹曼**：$E_b = \sigma T^4$
- **兰贝特定律**：$I = I_n \cos\theta$（余弦定律）

### 2. 实际物体
- 发射率：$\epsilon = \frac{E}{E_b}$
- 灰体：单色发射率 $\epsilon_\lambda = \text{常数}$

### 3. 基尔霍夫定律
$$\alpha = \epsilon$$
（在热平衡条件下，吸收率等于发射率；对于灰体任何温度均成立）

## 六、辐射换热计算

### 1. 角系数
- 定义：$X_{1,2} = \frac{从表面1发射落到表面2的辐射能}{表面1发射的总辐射能}$
- 相对性：$A_1 X_{1,2} = A_2 X_{2,1}$
- 完整性：$\sum_{j=1}^n X_{i,j} = 1$
- 代数法：利用已知形状的角系数组合求解

### 2. 灰体表面间的辐射换热
**表面辐射热阻概念：**
$$q = \frac{E_b - J}{(1-\epsilon)/\epsilon A} \quad \text{或} \quad q = \frac{E_b - J}{(1-\epsilon)/\epsilon}$$

**两个灰体表面间的辐射换热：**
$$\Phi_{1,2} = \frac{E_{b1} - E_{b2}}{\frac{1-\epsilon_1}{\epsilon_1 A_1} + \frac{1}{A_1 X_{1,2}} + \frac{1-\epsilon_2}{\epsilon_2 A_2}}$$

**特殊情形：**
- 两无限大平行平板：$q = \frac{\sigma(T_1^4 - T_2^4)}{\frac{1}{\epsilon_1} + \frac{1}{\epsilon_2} - 1}$
- 小物体被大包围：$\Phi_{1,2} = \epsilon_1 A_1 \sigma (T_1^4 - T_2^4)$

### 3. 网络法
将辐射换热系统转化为电阻网络：  
- 表面热阻：$\frac{1-\epsilon}{\epsilon A}$  
- 空间热阻：$\frac{1}{A_1 X_{1,2}}$  
热流 = 势差 / 总热阻，用电路规律求解。
