### 一、核心概念区分

| 概念 | 核心观点 | 代表人物 | 与发展心理学的关系 |
| :--- | :--- | :--- | :--- |
| **习性学 (Ethology)** | 研究**动物在自然环境中的行为**，强调行为的**进化适应意义**和**生物基础**。 | 康拉德·洛伦兹(Konrad Lorenz)、尼可·廷伯根(Niko Tinbergen) | 用于解释**依恋**、**关键期/敏感期**、**攻击行为**等具有生物根源的发展现象。 |
| **行为主义 (Behaviorism)** | 研究**可观察、可测量的行为**，强调**环境刺激**和**经验学习**（强化、惩罚）对行为的塑造。 | 华生(John B. Watson)、斯金纳(B.F. Skinner) | 用于解释**行为的习得**，如儿童如何通过模仿和强化学习社会行为、语言等。 |
| **社会学习理论 (Social Learning Theory)** | 是行为主义的延伸，强调**观察学习**、**榜样**和**认知因素**（如注意、记忆）在行为习得中的作用，不只依赖直接强化。 | 阿尔伯特·班杜拉(Albert Bandura) | 它融合了行为主义和学习理论，用于解释**性别角色发展**、**亲社会行为**和**攻击行为**的社会习得过程。 |

### 二、详细解释与发展心理学中的应用

#### 1. 习性学 (Ethology)

- **一句话总结**：动物在自然中，为了生存和繁衍，进化出了特定的行为模式。
- **与发展心理学的结合**：
    - **依恋理论**：鲍尔比运用习性学的观点，认为婴儿与照料者之间形成依恋（寻求亲近、分离焦虑）是一种**进化而来的生存机制**（为了获得保护）。这与行为主义认为的“依恋源于喂食”完全不同。
    - **关键期/敏感期**：习性学之父洛伦兹发现了“印刻”现象（刚出生的小鹅会跟随第一个移动的物体），证明了某些行为的学习存在一个关键期。在发展心理学中，这被引申为语言、依恋等能力发展的敏感期。
    - **攻击行为**：习性学认为攻击行为有其生物和进化根源（如争夺资源、保护领地），而不仅仅是后天习得的。

#### 2. 行为主义 (Behaviorism)

- **一句话总结**：“给我一打健康的婴儿，我能把他们训练成任何类型的人。”（华生）
- **与发展心理学的结合**：
    - **极端的环境论**：行为主义彻底否定遗传和内部心理过程的作用，认为儿童的全部行为（包括语言、情绪、人格）都是**被环境塑造**的结果。华生是典型代表。
    - **操作性条件作用**：斯金纳通过强化和惩罚，解释了儿童如何通过行为后果来学习新行为或改变行为频率。例如，儿童因为说“谢谢”得到表扬（正强化），从而更愿意说礼貌用语。
    - **局限性**：完全忽视了个体的主动性、认知过程、遗传和生物因素的影响。

#### 3. 社会学习理论 (Social Learning Theory)

- **一句话总结**：儿童可以通过**观察别人的行为**及其结果来学习，不一定需要自己亲身经历。
- **与发展心理学的结合**：
    - **观察学习与榜样**：班杜拉的波波玩偶实验经典地证明了这一点：儿童看到成人榜样攻击玩偶后，会模仿这种行为。这解释了**攻击行为的习得**。
    - **替代强化和替代惩罚**：看到榜样因为某种行为被奖励（替代强化），儿童更可能模仿；看到被惩罚（替代惩罚），则更可能抑制。
    - **性别发展**：儿童通过观察同性别父母、同伴或媒体中的榜样，学习什么是“男性”或“女性”的行为，并通过外界的强化来巩固这些行为。

### 三、如何区分使用——来自你的笔记

结合你的笔记，你可以在考试中这样判断：

1.  **看到“依恋是进化适应”、“内部工作模型”、“安全基地” -> 找鲍尔比 -> 这是习性学视角。**
2.  **看到“环境决定一切”、“刺激-反应”、“强化塑造行为” -> 找华生、斯金纳 -> 这是行为主义视角。**
3.  **看到“观察学习”、“榜样”、“模仿”、“替代强化” -> 找班杜拉 -> 这是社会学习理论视角。**
4.  **三者之间的核心区别**：
    - **习性学**：行为是先天的、适应性的。 (与其他两者最不同)
    - **行为主义**：行为是被直接强化出来的。
    - **社会学习理论**：行为可以通过观察榜样学来，靠间接经验。

## 二、各视角详细说明

### 1. 精神分析视角 (Psychoanalytic Perspective)

**一句话**：儿童行为由内在心理冲突和早期经验驱动。

**代表人物**：
- **弗洛伊德（高频）**：心理性欲发展理论，强调童年性心理发展阶段的成功或固着会影响人格。
- **埃里克森（高频）**：心理社会发展理论，强调社会文化对自我发展的影响，人生有八个心理社会阶段。

**核心概念**：无意识、本我-自我-超我、心理性欲阶段/心理社会阶段、固着、同一性危机。

**和发展心理学的关系**：最早强调童年早期经验对成年后人格和心理健康影响的理论；推动了关于依恋、亲子关系、情绪发展的研究。埃里克森是弗洛伊德的修正与发展。

**别和谁混**：弗洛伊德是“性欲阶段”——口唇期、肛门期等；埃里克森是“社会阶段”——信任对不信任、自主对羞耻等。

---

### 2. 认知发展视角 (Cognitive-Developmental Perspective)

**一句话**：儿童是主动的思想家，通过与环境互动逐步建构知识。

**代表人物**：
- **皮亚杰（高频）**：认知发展阶段理论：感知运动期、前运算期、具体运算期、形式运算期。核心是图式、同化、顺应、平衡。
- **信息加工理论**：将大脑比作计算机，关注注意、记忆、策略等认知过程随年龄的变化。

**核心概念**：图式、同化、顺应、平衡、认知发展阶段、编码、提取、元认知。

**和发展心理学的关系**：彻底改变了人们对儿童思维的理解——儿童不是“小大人”，以独特方式思考世界。皮亚杰的理论是发展心理学最经典的部分之一。

**别和谁混**：
- 皮亚杰 vs 维果茨基：两人都关注认知发展，但皮亚杰强调儿童独自探索，维果茨基强调社会互动和成人帮助。
- 皮亚杰 vs 科尔伯格：科尔伯格基于皮亚杰的研究，发展了道德认知发展阶段理论。

---

### 3. 社会文化视角 (Sociocultural Perspective)

**一句话**：认知发展是在社会互动和文化传递中发生的。

**代表人物**：
- **维果茨基（高频）**：最近发展区、脚手架、语言在认知中的中介作用。

**核心概念**：最近发展区 (ZPD)、脚手架、文化工具（语言、文字）、内化、共同活动。

**和发展心理学的关系**：维果茨基强调教学和发展的关系：**好的教学应走在发展前面**，即在最近发展区内通过他人帮助完成高难度任务，促进发展。他的理论广泛应用于教育实践。

**别和谁混**：主要和皮亚杰区分——皮亚杰是“独立探索者”，维果茨基是“社交学习者”。

---

### 4. 习性学/进化视角 (Ethological/Evolutionary Perspective)

**一句话**：许多行为有其进化根源和适应价值，在关键期发展。

**代表人物**：
- **洛伦兹**：印刻现象——小鹅出生后短时内会跟随首个移动物体。
- **鲍尔比（高频）**：依恋理论——婴儿对主要照料者的依恋是一种进化适应机制。

**核心概念**：关键期/敏感期、印刻、适应价值、内部工作模型。

**和发展心理学的关系**：解释了为什么婴儿会形成依恋（不是为了食物，而是为了安全和保护）；为什么某些能力（如语言）应在特定时期获得；为什么儿童对环境的某些刺激有先天倾向（如对陌生人焦虑）。

**别和谁混**：与行为主义根本对立：行为主义认为行为是后天习得，习性学认为行为有其先天生物根源。

---

### 5. 生态系统视角 (Ecological Systems Perspective)

**一句话**：发展是在环境的多层次系统中发生的，各系统之间有交互影响。

**代表人物**：
- **布朗芬布伦纳**：生态系统理论——微系统、中系统、外系统、宏系统、时间系统。

**核心概念**：
- **微系统**：最直接接触的环境（家庭、学校、同伴群体）
- **中系统**：微系统之间的交互（如父母与教师的沟通）
- **外系统**：不直接接触但影响个体的环境（如父母的工作场所、社区资源）
- **宏系统**：文化、价值观、法律等大环境
- **时间系统**：时间变迁带来的影响（如家庭搬迁、历史事件）

**和发展心理学的关系**：提醒我们不能只看个体，而要看到个体与环境系统的复杂互动。例如，父母工作压力可能影响亲子关系，进而影响儿童发展。

## 三、可用来对比的元理论维度

除了具体理论，还可以从以下根本问题角度去**区分各理论立场**：

| 元问题 | 不同立场 | 对应理论示例 |
| :--- | :--- | :--- |
| **天性vs教养** | 天性：遗传起主导 | 习性学（依恋有生物根源） |
| | 教养：环境起主导 | 行为主义（华生：环境决定一切） |
| | 交互：两者共同作用 | 认知发展（遗传与环境的交互建构）、生态系统理论 |
| **连续vs阶段** | 连续：发展是逐渐累积的 | 行为主义、信息加工理论、社会学习 |
| | 阶段：发展有质的飞跃 | 弗洛伊德、皮亚杰、埃里克森 |
| **主动vs被动** | 主动：儿童是发展的积极参与者 | 皮亚杰（主动建构者）、社会文化（社会互动参与者） |
| | 被动：发展是环境塑造的产物 | 行为主义（环境塑造者） |
| **普遍vs个体** | 普遍：发展阶段和机制普遍适用 | 皮亚杰（认知发展阶段普遍）、弗洛伊德（人格发展阶段普遍） |
| | 个体：个体经验和文化差异很重要 | 生态系统理论（文化系统差异）、社会文化理论（文化工具差异） |

## 四、考法示例：如何用多角度分析同一个发展主题

以你在笔记中看到的**攻击行为**为例，不同的理论视角会有完全不同的解释：

| 理论视角 | 对攻击行为的解释 |
| :--- | :--- |
| **精神分析** | 攻击是内在驱力（如死亡本能）的释放，其他管理不当则外泄为攻击。 |
| **习性学** | 攻击具有进化和生存功能（争夺资源、领地保护），在人类中有生物基础。 |
| **行为主义** | 攻击行为因过去的正强化（攻击成功了）或模仿（观察了暴力榜样）而被习得。 |
| **社会学习（班杜拉）** | 儿童通过观察暴力榜样（如媒体、家庭成员）和替代强化（看到暴力得到奖励）来习得攻击。 |
| **生态系统** | 攻击受多层系统影响：暴力家庭（微系统）、暴力同伴群体（微系统）、社区暴力（外系统）、文化崇尚暴力（宏系统）。 |
| **认知发展** | 攻击行为发展随认知成熟而变化，年幼儿童因自我中心或因果推理不成熟容易冲动攻击。 |

考试时如果看到题目给了材料，你可以：
1. 先判断问题问的是哪方面（人格？认知？社会性？攻击？依恋？）
2. 再从相应理论中根据关键词匹配
3. 如果题目问“用X理论解释”，对应语境选对应视角
